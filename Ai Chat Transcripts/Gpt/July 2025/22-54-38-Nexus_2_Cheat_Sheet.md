## ASSISTANT
Base64 is an encoding scheme used to represent binary data (such as images, files, or any kind of raw data) in a text format. It translates the binary data into a string of characters that can be safely stored or transmitted over text-based systems like email or JSON without losing integrity.

### Why Use Base64?
1. **Safe Transmission:** It avoids issues with systems that don't handle raw binary data well by converting it to plain text.
2. **Cross-Platform Compatibility:** Makes data transportable between different systems or environments that might interpret binary data differently.
3. **Simplified Embedding:** Useful for embedding images or other resources in HTML, CSS, or Markdown.

### How Does It Work?
- Binary data is divided into groups of 3 bytes (24 bits).
- These 24 bits are then split into 4 groups of 6 bits each.
- Each 6-bit group is mapped to a character from the Base64 character set:
  ```
  A-Z, a-z, 0-9, +, /
  ```
- If the original data isn't a multiple of 3 bytes, padding characters `=` are added to ensure proper encoding.

### Example:
- **Input (binary):** `Hello` → `01001000 01100101 01101100 01101100 01101111`
- **Base64 Output:** `SGVsbG8=`

### Common Uses:
1. **Data Encoding:** Sending binary data in text-only protocols (e.g., JSON, XML).
2. **Embedding Images in HTML/CSS:** Example: `data:image/png;base64,...`
3. **API Communication:** Encoding data for headers or payloads.

### Limitations:
- **Increased Size:** Base64 encoding increases data size by approximately 33%.
- **Not Secure:** It is not encryption—encoded data can be easily decoded.
