## ASSISTANT
To clear out all old app data on a Windows 10 reset, there are two main reset options to consider, depending on how thorough you want to be:

### 1. **Reset with the "Remove everything" Option**
   This method will reset Windows 10, delete all installed applications, and clear user data and files, including app data.

   1. **Go to Settings**: Open the **Settings** app (press **Windows + I**).
   2. **Navigate to Update & Security**: Click on **Update & Security**.
   3. **Select Recovery**: In the left sidebar, choose **Recovery**.
   4. **Start Reset**: Under **Reset this PC**, click on **Get started**.
   5. **Choose the Option to Remove Everything**: When prompted, choose **Remove everything**.
   6. **Select Data Removal Method**: Select **Remove files and clean the drive** if you want to securely erase all data, which is more thorough.

   This option will wipe all personal files, settings, and apps, restoring your PC to a near-factory state.

### 2. **Fresh Start with the "Cloud Download" Option**
   Windows also offers a "Fresh Start" (under the same "Reset this PC" settings) that uses a cloud download of Windows 10, ensuring a clean OS installation without retaining old app data. This option downloads the latest Windows 10 version from the cloud and performs a clean installation, which can sometimes be even more effective at removing all previous data.

## ASSISTANT
In Option 1, choosing "Remove everything" will delete the following types of personal files:

1. **User Profile Data**: All files in the user profile folders, including:
   - **Desktop files** (anything saved directly on the desktop).
   - **Documents** (files saved in the "Documents" folder).
   - **Downloads** (all files in the "Downloads" folder).
   - **Pictures** (images stored in the "Pictures" folder).
   - **Music** (files in the "Music" folder).
   - **Videos** (videos in the "Videos" folder).

2. **Installed Applications**: All applications not bundled with Windows, including third-party apps you've installed. After the reset, you’ll only have the default apps that come with Windows.

3. **App Data**: Data for applications stored in the `AppData` folder within each user’s profile, which includes settings, caches, and user-specific data for applications.

4. **Custom Settings and Configurations**: Any customized settings, such as display preferences, network settings, and personalization configurations, will be reset to their defaults.

5. **Registry Entries and System-Wide Settings**: Any system modifications or registry tweaks will be removed, resetting everything to the original Windows 10 defaults.

### Files Not Removed
Files on other partitions or drives (like D: or external drives) are typically not affected unless you select specific options to clean additional drives. However, it’s always good practice to back up essential data before performing a reset, especially if it’s stored outside the main user profile directories.
