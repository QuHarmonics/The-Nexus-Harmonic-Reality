## ASSISTANT
To add a **shadow to text in CSS**, you use the `text-shadow` property. Here's the basic syntax:

```css
text-shadow: [horizontal offset] [vertical offset] [blur radius] [color];
```

### 🔧 Example:
```css
.my-text {
  color: white;
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.7);
}
```

### 🔍 Explanation:
- `2px` → shadow moves 2 pixels right
- `2px` → shadow moves 2 pixels down
- `4px` → blur radius
- `rgba(0, 0, 0, 0.7)` → semi-transparent black shadow

### 💡 Tips:
- You can stack multiple shadows by comma-separating them:
```css
text-shadow: 1px 1px 2px black, 0 0 1em red;
```
