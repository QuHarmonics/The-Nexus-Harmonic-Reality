### Retrying *until* you connect

By default, `WithAutomaticReconnect()` only kicks in *after* you’ve successfully called `StartAsync()` at least once—you still need to handle a *first-connect* failure yourself. If you want your client to *keep retrying forever* until it actually gets a live connection, you can wrap your initial `StartAsync()` in a simple loop:

```csharp
private async Task ConnectWithRetryAsync(HubConnection connection, string hubName)
{
    while (true)
    {
        try
        {
            await connection.StartAsync();
            Log.Information("Connected to {Hub}. State: {State}", hubName, connection.State);
            NotifyStateChanged(hubName, connection.State);
            break;  // success! exit loop
        }
        catch (Exception ex)
        {
            Log.Warning(ex, "Failed to connect to {Hub}, retrying in 5s…", hubName);
            await Task.Delay(TimeSpan.FromSeconds(5));
        }
    }
}
```

In C#, a `Dictionary<TKey,TValue>` (and by extension `ConcurrentDictionary<TKey,TValue>`) is a data structure that maps **keys** of type `TKey` to **values** of type `TValue`. When you write:

```csharp
_connections[url] = connection;
```

you are storing the `HubConnection` instance under the key whose value is the string in `url`. Later, when you call:

```csharp
_connections.TryGetValue(url, out var conn);
```

the dictionary attempts to locate an entry whose key **exactly** matches the string you passed in.  

---

### Why your lookup may “fail”  

1. **Exact-match requirement**  
   - Dictionaries in .NET use the `Equals` (and `GetHashCode`) implementation of the key type to determine equality.  
   - Two strings that differ by even a single character—extra slash, different case, leading/trailing whitespace—will not be considered the same key.  

2. **Population vs. lookup mismatch**  
   - If you populated `_connections` with keys `"https://api.example.com/canbus"` but later call `GetConnection("https://api.example.com/CanBus")`, the lookup will fail because of the case difference.  

---

### How `TryGetValue` works  

```csharp
public bool TryGetValue(TKey key, out TValue value);
```

- **Returns** `true` if an entry with that key exists; in that case, `value` is set to the stored object.  
- **Returns** `false` if no entry with that key exists; `value` will be assigned the default for `TValue` (in this case, `null`).  

Your original shorthand:

```csharp

```

        private readonly ConcurrentDictionary<string, HubConnection> _connections = new();

        /// <summary>
        /// Raised whenever any hub’s connection state changes.
        /// </summary>
        public event Action<string, HubConnectionState>? ConnectionStateChanged;

        public MobileCanBusClientConnectionManager(IConfiguration config)
        {
            _hubUrls = config
                .GetSection("CanBusHubs")
                .Get<Dictionary<string, string>>()
                ?? throw new ArgumentException("Configuration section 'CanBusHubs' is missing or empty.");

            if (_hubUrls.Count == 0)
                throw new ArgumentException("Configuration section 'CanBusHubs' must define at least one hub.");
        }

        /// <summary>
        /// Initializes and starts all HubConnections, retrying indefinitely on first-connect failures.
        /// </summary>
        public async Task InitializeAsync()
        {
            foreach (var kvp in _hubUrls)
            {
                var key = kvp.Key;
                var url = kvp.Value;

                Log.Information("Initializing connection for hub '{Key}' at {Url}", key, url);

                var connection = new HubConnectionBuilder()
                    .WithUrl(url)
                    .WithAutomaticReconnect()
                    .Build();

                // Built-in reconnect events
                connection.Reconnecting += error =>
                {
                    Log.Warning("Reconnecting hub '{Key}'. Reason: {Reason}", key, error?.Message ?? "Unknown");
                    NotifyStateChanged(key, HubConnectionState.Reconnecting);
                    return Task.CompletedTask;
                };

                connection.Reconnected += connectionId =>
                {
                    Log.Information("Reconnected hub '{Key}'. ConnectionId: {ConnectionId}", key, connectionId);
                    NotifyStateChanged(key, HubConnectionState.Connected);
                    return Task.CompletedTask;
                };

                connection.Closed += async error =>
                {
                    Log.Warning("Hub '{Key}' closed. Reason: {Reason}", key, error?.Message ?? "None");
                    NotifyStateChanged(key, HubConnectionState.Disconnected);

                    // Retry initial start on closure
                    await ConnectWithRetryAsync(connection, key, url).ConfigureAwait(false);
                };

                // Perform the initial connect with retry logic
                await ConnectWithRetryAsync(connection, key, url).ConfigureAwait(false);

                // Store the live connection under its key
                _connections[key] = connection;
            }
        }

        /// <summary>
        /// Attempts to start the connection until successful (5s back-off).
        /// </summary>
        private static async Task ConnectWithRetryAsync(HubConnection connection, string key, string url)
        {
            while (true)
            {
                try
                {
                    await connection.StartAsync().ConfigureAwait(false);
                    Log.Information("Hub '{Key}' connected. State: {State}", key, connection.State);
                    NotifyStaticStateChanged(connection, key);
                    break;
                }
                catch (Exception ex)
                {
                    Log.Error(ex, "Failed to connect hub '{Key}' at {Url}. Retrying in 5s…", key, url);
                    await Task.Delay(TimeSpan.FromSeconds(5)).ConfigureAwait(false);
                }
            }
        }

        /// <summary>
        /// Provides the HubConnection associated with the given key, or null if not found.
        /// </summary>
        public HubConnection? GetConnection(string key)
            => _connections.TryGetValue(key, out var conn) ? conn : null;

        /// <summary>
        /// Returns the current connection state, or Disconnected if the key is unregistered.
        /// </summary>
        public HubConnectionState GetConnectionState(string key)
            => _connections.TryGetValue(key, out var conn)
                ? conn.State
                : HubConnectionState.Disconnected;

        private void NotifyStateChanged(string key, HubConnectionState state)
        {
            Log.Information("Connection state changed for hub '{Key}': {State}", key, state);
            ConnectionStateChanged?.Invoke(key, state);
        }

        // Helper to invoke the instance event from the static retry method
        private static void NotifyStaticStateChanged(HubConnection connection, string key)
        {
            if (connection is MobileCanBusClientConnectionManager mgr)
                mgr.NotifyStateChanged(key, connection.State);
        }
