### 1. BIOS Configuration:
Enter BIOS Setup by pressing `DEL` during boot, then:

- **Disable unused peripherals:**
  - Disable serial ports (`COM ports`) if not used.
  - Disable onboard VGA if you're using a separate GPU.
  - Disable unused SATA ports.

  - Under the Boot menu, set boot mode to UEFI for faster boot times.

- **Adjust Boot Priority:**

- Go to **Advanced → Boot Feature** and enable:
  - **Quiet Boot:** Minimizes the diagnostic messages.
  - **Fast Boot:** Reduces time spent on memory initialization and other checks.

- If you aren't actively using IPMI (remote management), disable BMC/IPMI features:
  - Set jumper `JPB1` to disabled.
  - Disable IPMI LAN in BIOS if available.

### 4. Reduce Peripheral Enumeration Time:
- Under BIOS setup:
  - Disable unused PCIe slots or set PCIe detection to "Auto" rather than "Force Gen3."
  - If you have legacy devices connected (e.g., USB 2.0), consider removing or updating them.

### 5. Ensure Firmware and BIOS are Updated:
- BIOS updates often contain optimizations for boot performance:
  - [Supermicro X10DRi BIOS Updates](https://www.supermicro.com)

### 6. Hardware Optimization:
- Use faster boot storage (e.g., NVMe or high-speed SSDs).
- Minimize the number of connected USB devices, especially external drives or legacy devices that slow down boot detection.

**CMS (Compatibility Support Module)** is a BIOS/UEFI setting that enables legacy BIOS compatibility within UEFI firmware. It allows the system to boot legacy operating systems and devices that do not support UEFI.

**Functions of CMS:**
- Emulates legacy BIOS services to support non-UEFI OS installations.
- Enables legacy option ROMs for storage controllers, network adapters, and video cards.
- Supports MBR partition scheme instead of GPT.

**Typical CMS Settings:**
- **Enabled**: Legacy OSes and devices can function.
- **Disabled**: Pure UEFI mode; faster boot, secure boot enabled.
- **Auto**: BIOS automatically determines based on installed OS and hardware.

**Recommendation:** Disable CMS for modern systems using GPT and UEFI OS installations. Enable only if legacy device support is required.

This BIOS setting affects how memory-mapped I/O (MMIO) space—specifically **below the 4 GB physical address boundary**—is handled across **NUMA sockets** in multi-socket systems (like dual-CPU X99/C610 boards).

- **Socket Interleave Below 4G** controls whether **devices' MMIO regions (<4 GB)** are **interleaved across CPU sockets** or assigned **locally** to one socket.

---

### ⚙️ Options

| Setting       | Behavior                                                   |
|---------------|------------------------------------------------------------|
| **Enabled**   | MMIO (<4GB) is **interleaved** across all sockets, which can help **bandwidth balance** and reduce access latency in uniform memory access (UMA) configurations. |

---

- **Uniform workloads** with devices spread across sockets.
- Systems **not using virtualization passthrough** or **tight NUMA control**.

---

- Systems with **PCIe passthrough** (e.g., VFIO, SR-IOV, ESXi).

### ✅ When to Enable RAS Mode

| RAS Mode      | Description                          | Trade-off                  |
|---------------|--------------------------------------|----------------------------|
| **Lockstep**  | Two channels work in lockstep; can correct multi-bit errors | Reduces usable memory, adds latency |
| **Mirroring** | Data written identically to two channels (like RAID 1) | 50% capacity loss |
| **Sparing**   | Reserved ranks used when a rank is predicted to fail | Slight memory loss, some latency |
| **Independent (Disabled)** | Full capacity, normal ECC | ✅ Best performance |

---

### 🧭 Recommendations

| Use Case                              | RAS Mode Setting |
|---------------------------------------|------------------|
| High-performance workloads (DB, HPC)  | ❌ **Disabled** (independent mode) |
| Virtualization host with ECC          | ❌ **Disabled** unless critical uptime needed |
| Critical systems (finance, SCADA)     | ✅ **Enable** (e.g., mirroring or lockstep) |
| General-purpose server with ECC       | ❌ **Disabled** (default safe choice) |

---

### Summary

| Setting            | Impact                                    |
|---------------------|--------------------------------------------|
| **Disabled (default)** | ✅ Max performance and full capacity; ECC still works |
| **Enabled (Lockstep/Mirroring/Sparing)** | Fault tolerance at the cost of performance or memory size |
