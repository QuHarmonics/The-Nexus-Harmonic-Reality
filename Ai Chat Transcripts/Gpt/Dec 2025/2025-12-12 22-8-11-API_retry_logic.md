- any non-2xx / connectivity / timeout → `Success=false` **and** put the exception/message in the result.

## ASSISTANT
That message is from **Entity Framework Core** and it’s warning that your inheritance-mapping choice (Table-Per-Concrete-Type, or **TPC**) conflicts with how EF expects to generate key values for the `Id` column.

### What’s going on

In **TPC**, every concrete class in the hierarchy maps to its own physical table, and **each table must manage its primary keys itself**.  
If EF thinks the `Id` should be **database-generated** (e.g., `IDENTITY`, `AUTOINCREMENT`, or `ValueGeneratedOnAdd()`), but the mapping can’t safely apply that to multiple independent tables in one hierarchy, you get this error.

In short:
> “I’m using TPC and EF is trying to generate my key automatically, but it doesn’t know how because each concrete type/table is separate.”

---

### Typical causes

1. You declared inheritance like:
   ```csharp
   modelBuilder.Entity<JobBase>().UseTpcMappingStrategy();
   ```
   and one or more derived types have:
   ```csharp
   builder.Property(e => e.Id)
          .ValueGeneratedOnAdd();   // identity column
   ```
2. The database columns for `Id` in different tables have conflicting or missing identity settings.
3. You expect EF to assign `Guid` or numeric IDs automatically, but you didn’t mark it consistently across all tables.

---

### Ways to fix it

#### ✅ Option 1: Use non-generated keys
If you’re fine assigning IDs yourself:
```csharp
builder.Property(e => e.Id)
       .ValueGeneratedNever();
```
You’ll create IDs in code (e.g., `Guid.NewGuid()` or manual int sequence).

#### ✅ Option 2: Make each concrete type manage its own identity
If you want database-generated ints, ensure every table has its own identity column and tell EF it’s generated:
```csharp
builder.Property(e => e.Id)
       .UseIdentityColumn(); // or .ValueGeneratedOnAdd()
```
and **do this in each concrete entity configuration** (not only in the base type).

#### ✅ Option 3: Change inheritance strategy
If you didn’t really need TPC, Table-Per-Hierarchy (**TPH**) is usually simpler:
```csharp
modelBuilder.Entity<JobBase>().UseTphMappingStrategy();
```
Then a single table stores all subclasses and a single identity generator works fine.

---

### Quick summary

| Strategy | Tables | Id generation support | Typical fix |
|-----------|---------|-----------------------|--------------|
| **TPC** | one per class | each table must generate its own keys | configure per type or use non-generated |
| **TPH** | one table | one identity sequence works | switch if inheritance is light |
| **TPT** | one per level | identity can work if base defines Id | another alternative |

---

So the message really means:
> “You told EF each subclass has its own table (TPC), but your Id is set to auto-generate from a single source. Either make each table responsible for its own Id generation, or assign the Id manually.”

```csharp
                    .Select(d => d.Trim());
```

## ASSISTANT

## Best pattern: “Discovery probe” on a fixed UDP port
**How it works**
1. **Server Manager** opens a UDP listener on a known port (e.g. `45678`) on the LAN.
2. Client (your desktop app) sends a **broadcast** UDP packet to `255.255.255.255:45678` (or subnet broadcast like `192.168.1.255`).
3. Server replies unicast with a small JSON blob:
   - `ApiBaseUrl` (including port)
   - `SignalRUrl`
   - `ServerName`, `Version`, maybe `MachineId`
4. Client then verifies by calling `GET /health` (or `/api/ping`) before saving settings.

**Why this wins**
- Fast (single packet round-trip)
- No port scanning
- Works even if the server port is not default (because it’s included in the reply)
- You can return *multiple* servers and let the user choose

**Security note**
Add a simple guard so random machines can’t impersonate your server:
- include an HMAC signature in the response (shared key baked into both apps), or
- require a one-time pairing code shown on the server UI

## Also good: mDNS / DNS-SD (Bonjour-style)
If you want “it just shows up” on the LAN:
- Server advertises a service like `_logistix-api._tcp.local`
- Client browses that service and reads host/port

This is elegant, but Windows support is “library-dependent” (you’ll use a Zeroconf/mDNS package).

## Acceptable fallback: Subnet scan (only if you must)
If you can’t change the server to advertise:
1. Determine local subnets from network interfaces.
2. Enumerate IPs in those subnets.
3. Try a very small set of ports you own (e.g. `7071`, `443`, `80`, `5072`) and hit a known endpoint like `/health`.
4. Stop on first valid response.

This is slower/noisier and will eventually annoy networks, but it works.

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Net;
using System.Net.NetworkInformation;
using System.Net.Sockets;
using System.Security.Cryptography;
using System.Text;
using System.Text.Json;
using System.Threading;
using System.Threading.Tasks;
using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Logging;
using Microsoft.Extensions.Options;

public sealed class DiscoveryOptions
{
    // Fixed UDP port clients will broadcast to
    public int UdpPort { get; set; } = 45678;

    // Your API + SignalR ports (or full URLs if you want)
    public int ApiPort { get; set; } = 7071;
    public int SignalRPort { get; set; } = 5072;

    // Optional: shared secret to sign responses (prevents spoofing)
    public string? SharedSecret { get; set; } = null;

    // Optional: set if you want HTTPS / WSS
    public bool UseHttps { get; set; } = false;
}

public sealed class UdpDiscoveryHostedService : BackgroundService
{
    private readonly ILogger<UdpDiscoveryHostedService> _log;
    private readonly DiscoveryOptions _opt;

    public UdpDiscoveryHostedService(
        ILogger<UdpDiscoveryHostedService> log,
        IOptions<DiscoveryOptions> options)
    {
        _log = log;
        _opt = options.Value;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        using var udp = new UdpClient(AddressFamily.InterNetwork);

        // bind to all interfaces on the fixed discovery port
        udp.Client.SetSocketOption(SocketOptionLevel.Socket, SocketOptionName.ReuseAddress, true);
        udp.EnableBroadcast = true;
        udp.Client.Bind(new IPEndPoint(IPAddress.Any, _opt.UdpPort));

        _log.LogInformation("UDP discovery listening on port {Port}", _opt.UdpPort);

        while (!stoppingToken.IsCancellationRequested)
        {
            UdpReceiveResult recv;
            try
            {
                recv = await udp.ReceiveAsync(stoppingToken);
            }
            catch (OperationCanceledException)
            {
                break;
            }
            catch (Exception ex)
            {
                _log.LogWarning(ex, "UDP discovery receive failed");
                continue;
            }

            try
            {
                // Expect either plain text "LOGISTIX_DISCOVERY_V1" or JSON
                var payload = Encoding.UTF8.GetString(recv.Buffer);
                if (!IsDiscoveryRequest(payload, out var nonce))
                    continue;

                var remoteIp = recv.RemoteEndPoint.Address;
                var bestLocalIp = PickBestLocalIPv4ForRemote(remoteIp) ?? GetAnyLocalIPv4() ?? IPAddress.Loopback;

                string schemeHttp = _opt.UseHttps ? "https" : "http";
                string schemeWs   = _opt.UseHttps ? "wss" : "ws";

                var response = new DiscoveryResponse
                {
                    Type = "LOGISTIX_DISCOVERY_RESPONSE_V1",
                    Nonce = nonce,
                    ServerName = Environment.MachineName,
                    ApiBaseUrl = $"{schemeHttp}://{bestLocalIp}:{_opt.ApiPort}",
                    SignalRUrl = $"{schemeWs}://{bestLocalIp}:{_opt.SignalRPort}",
                    Utc = DateTimeOffset.UtcNow.ToString("O"),
                    Version = typeof(UdpDiscoveryHostedService).Assembly.GetName().Version?.ToString() ?? "unknown"
                };

                // Optional signature (recommended if you’re going to auto-accept)
                if (!string.IsNullOrWhiteSpace(_opt.SharedSecret))
                {
                    response.Signature = SignResponse(response, _opt.SharedSecret!);
                }

                var json = JsonSerializer.Serialize(response);
                var bytes = Encoding.UTF8.GetBytes(json);

                await udp.SendAsync(bytes, bytes.Length, recv.RemoteEndPoint);
            }
            catch (Exception ex)
            {
                _log.LogDebug(ex, "UDP discovery request handling failed");
            }
        }

        _log.LogInformation("UDP discovery stopped");
    }

    private static bool IsDiscoveryRequest(string payload, out string nonce)
    {
        nonce = "";

        payload = payload?.Trim() ?? "";

        if (string.Equals(payload, "LOGISTIX_DISCOVERY_V1", StringComparison.OrdinalIgnoreCase))
        {
            nonce = Guid.NewGuid().ToString("N");
            return true;
        }

        // JSON request: {"type":"LOGISTIX_DISCOVERY_V1","nonce":"..."}
        try
        {
            using var doc = JsonDocument.Parse(payload);
            var root = doc.RootElement;

            if (!root.TryGetProperty("type", out var typeEl)) return false;
            if (!string.Equals(typeEl.GetString(), "LOGISTIX_DISCOVERY_V1", StringComparison.OrdinalIgnoreCase)) return false;

            if (root.TryGetProperty("nonce", out var nonceEl))
                nonce = nonceEl.GetString() ?? "";

            if (string.IsNullOrWhiteSpace(nonce))
                nonce = Guid.NewGuid().ToString("N");

            return true;
        }
        catch
        {
            return false;
        }
    }

    private static IPAddress? GetAnyLocalIPv4()
    {
        foreach (var ni in NetworkInterface.GetAllNetworkInterfaces())
        {
            if (ni.OperationalStatus != OperationalStatus.Up) continue;
            if (ni.NetworkInterfaceType == NetworkInterfaceType.Loopback) continue;

            var ipProps = ni.GetIPProperties();
            foreach (var ua in ipProps.UnicastAddresses)
            {
                if (ua.Address.AddressFamily != AddressFamily.InterNetwork) continue;
                if (IPAddress.IsLoopback(ua.Address)) continue;
                return ua.Address;
            }
        }
        return null;
    }

    private static IPAddress? PickBestLocalIPv4ForRemote(IPAddress remote)
    {
        // Choose the local IPv4 whose subnet matches the remote (best guess)
        if (remote.AddressFamily != AddressFamily.InterNetwork) return GetAnyLocalIPv4();

        foreach (var ni in NetworkInterface.GetAllNetworkInterfaces())
        {
            if (ni.OperationalStatus != OperationalStatus.Up) continue;
            if (ni.NetworkInterfaceType == NetworkInterfaceType.Loopback) continue;

            var ipProps = ni.GetIPProperties();
            foreach (var ua in ipProps.UnicastAddresses)
            {
                if (ua.Address.AddressFamily != AddressFamily.InterNetwork) continue;
                if (ua.IPv4Mask == null) continue;

                if (SameSubnet(ua.Address, remote, ua.IPv4Mask))
                    return ua.Address;
            }
        }

        return GetAnyLocalIPv4();
    }

    private static bool SameSubnet(IPAddress a, IPAddress b, IPAddress mask)
    {
        var ab = a.GetAddressBytes();
        var bb = b.GetAddressBytes();
        var mb = mask.GetAddressBytes();

        for (int i = 0; i < 4; i++)
        {
            if ((ab[i] & mb[i]) != (bb[i] & mb[i]))
                return false;
        }
        return true;
    }

    private static string SignResponse(DiscoveryResponse r, string secret)
    {
        // Sign stable fields only (avoid signature breaking on field reorder)
        var data = $"{r.Type}|{r.Nonce}|{r.ServerName}|{r.ApiBaseUrl}|{r.SignalRUrl}|{r.Version}";
        using var hmac = new HMACSHA256(Encoding.UTF8.GetBytes(secret));
        var sig = hmac.ComputeHash(Encoding.UTF8.GetBytes(data));
        return Convert.ToHexString(sig); // uppercase hex
    }

    private sealed class DiscoveryResponse
    {
        public string Type { get; set; } = "";
        public string Nonce { get; set; } = "";
        public string ServerName { get; set; } = "";
        public string ApiBaseUrl { get; set; } = "";
        public string SignalRUrl { get; set; } = "";
        public string Version { get; set; } = "";
        public string Utc { get; set; } = "";
        public string? Signature { get; set; } = null;
    }
}
```

```csharp
using Microsoft.Extensions.Logging;
using Microsoft.Extensions.Options;
using System;
using System.Net;
using System.Net.Sockets;
using System.Text;
using System.Text.Json;
using System.Threading;
using System.Threading.Tasks;

public sealed class UdpDiscoveryResponder : BackgroundService
{
    private const string DISCOVERY_PING = "LOGISTIX_DISCOVERY_V1";

    private readonly ILogger<UdpDiscoveryResponder> _log;
    private readonly DiscoveryOptions _opt;

    public UdpDiscoveryResponder(
        ILogger<UdpDiscoveryResponder> log,
        IOptions<DiscoveryOptions> options)
    {
        _log = log;
        _opt = options.Value;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        using var udp = new UdpClient(AddressFamily.InterNetwork);
        udp.EnableBroadcast = true;
        udp.Client.SetSocketOption(SocketOptionLevel.Socket, SocketOptionName.ReuseAddress, true);
        udp.Client.Bind(new IPEndPoint(IPAddress.Any, _opt.UdpPort));

        _log.LogInformation("UDP Discovery listening on 0.0.0.0:{Port}", _opt.UdpPort);

        while (!stoppingToken.IsCancellationRequested)
        {
            UdpReceiveResult recv;
```

```csharp
using System;
using System.Net;
using System.Net.Sockets;
using System.Text;
using System.Threading;
using System.Threading.Tasks;

private async Task<string?> ListenAsync(int timeoutMs = 5000)
{
    using var udp = new UdpClient(AddressFamily.InterNetwork);

    // Bind explicitly (cleaner than new UdpClient(9876) when you want options)
    udp.Client.SetSocketOption(SocketOptionLevel.Socket, SocketOptionName.ReuseAddress, true);
    udp.EnableBroadcast = true;
    udp.Client.Bind(new IPEndPoint(IPAddress.Any, 9876));

    using var cts = new CancellationTokenSource();
    cts.CancelAfter(timeoutMs);

    try
    {
        while (true)
        {
            // This WILL end on timeout via OperationCanceledException
            var result = await udp.ReceiveAsync(cts.Token);

            var message = Encoding.UTF8.GetString(result.Buffer);

            if (message.StartsWith("LOGISTIXS_SERVER_DISCOVERY|", StringComparison.OrdinalIgnoreCase))
            {
                var parts = message.Split('|', 2);
                if (parts.Length == 2 && !string.IsNullOrWhiteSpace(parts[1]))
                    return parts[1]; // API URL
            }
        }
    }
    catch (OperationCanceledException)
    {
        // timeout
        return null;
    }
    catch (SocketException)
    {
        // bind errors, etc.
        return null;
    }
    catch
    {
        return null;
    }
}
```
