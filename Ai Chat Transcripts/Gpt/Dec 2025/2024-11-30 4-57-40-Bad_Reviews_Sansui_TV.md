#### 3. **Connect Both Phones**
   - **Via Wi-Fi**:
     - Both phones need to be on the same Wi-Fi network for most VR controller apps to communicate.

   - **Via Bluetooth**:
     - Some apps allow pairing the phones via Bluetooth if Wi-Fi is not available.

#### 4. **Customize Controller Settings**
   - On the controller phone, configure the buttons and gestures. Some apps let you simulate touchpads, joysticks, or motion tracking.

#### 5. **Test the Setup**
   - Start a VR experience and use the controller phone to interact, select options, or navigate the virtual environment.
