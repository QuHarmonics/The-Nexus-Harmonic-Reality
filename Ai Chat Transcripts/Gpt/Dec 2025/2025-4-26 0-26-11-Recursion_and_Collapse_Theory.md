# ⚙️ Option 1: Set the Default Folder Permanently (Global Setting)

✅ **Quick steps:**

1. **Open Anaconda Navigator**.
2. In the main window, **click "Environments"**, and **activate** the environment you're using (e.g., `base` or custom env).
3. On the left, **click "Home"**.
4. Under **Jupyter Notebook**, click the **gear icon ⚙️** next to the "Launch" button.
5. Click **"Open Terminal"**.

6. In that terminal, **run this command to find your config file:**

   ```bash
   jupyter notebook --generate-config
   ```

   This creates a config file usually at:

   ```
   C:\Users\<YourUsername>\.jupyter\jupyter_notebook_config.py
   ```

7. **Open that file** in any text editor (VSCode, Notepad++, etc).

8. **Search** for this line (it will be commented out by default):

   ```python
   # c.NotebookApp.notebook_dir = ''
   ```

9. **Uncomment it** (remove the `#`) and **set it to your desired folder**, like:

   ```python
   c.NotebookApp.notebook_dir = 'C:/Users/Dean/Documents/Jupyter'
   ```

   👉 **Important:** Use **forward slashes `/`** or **double backslashes `\\`** for Windows paths.

10. **Save** the file.

11. Now every time you launch Jupyter Notebook from Anaconda Navigator or terminal, **it will start in that folder**!

---

# ⚡ Option 2: Temporary Change (Per-Launch)

✅ If you **don't want a permanent change**, just launch Jupyter manually from Anaconda Prompt:

1. Open **Anaconda Prompt**.
2. **Navigate** to the desired folder:

   ```bash

   ```

3. Then **launch Jupyter**:

   ```bash
   jupyter notebook
   ```

It will open **starting from that folder** just for that session.
