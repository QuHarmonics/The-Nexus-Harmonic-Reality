# Affine Congruential Residue Lattices: Period‑25 Tiling, Cropped Visibility Windows, and the Deterministic Appearance of “Hash‑Like” Chaos

**Author(s):** Dean A. Kulik (concept & discovery), Assistant (formalization and analysis)  
**Date:** January 2026  

---

## Abstract

We study a simple but surprisingly rich modular grid generator:

$$
r(a,b) \equiv s + u(a-1) + v(b-1) \pmod m,
$$

with integer parameters $(s,u,v,m)=(53,4,56,100)$ and integer coordinates $(a,b)\in\mathbb{Z}^2$ (typically $a,b\ge 1$). When the grid is *cropped* to a low‑dimensional “visibility window” (e.g., $a+b\le 10$) and optionally *filtered* through a representational band (e.g., printable ASCII), the resulting display resembles pseudorandom hash output despite being purely deterministic and linear.

This paper provides a complete, formal analysis of the generator as an **affine congruential lattice** (an additive congruential map from $\mathbb{Z}^2$ into $\mathbb{Z}_m$), derives its **exact periodicity** (a $25\times 25$ fundamental tile), characterizes the **restriction to a residue class modulo $4$**, and shows a reduction to a **$\mathbb{Z}_{25}$ model** that explains the “scrambling” effect within small crops. We also clarify the relationship to linear congruential generators (LCGs): the grid is not an LCG in the standard multiplicative sense; it is the degenerate $A=1$ additive case along any 1D traversal.

Beyond the specific parameters, we develop general theorems for $r(a,b)$, provide verification code and reproducible tables, and interpret the visual phenomenon as a rigorous example of **frame‑dependent apparent randomness**: the display looks chaotic until the generating frame is identified.

**Keywords:** modular arithmetic, affine lattice, additive congruential generator, LCG, periodic tiling, pseudorandomness, spectral structure, visibility windows.

---

## 1. Introduction

Apparent chaos can emerge from deterministic linear rules whenever:

1. values are mapped through a modulus,
2. the resulting field is observed only through a crop or projection, and
3. the observer’s representation filters out most states (e.g., printing only a subset of residues).

This paper analyzes a concrete instance that arose from a “grid of residues” displayed as numbers, hex bytes, and printable characters. The grid initially appeared hash‑like—scattered digits with occasional readable glyphs—yet collapsed instantly to a trivial generator once directional steps were recognized.

The contribution here is to treat that collapse as an object of study: a complete characterization of the generator, its periodicity, its reduced form, and why small windows can mimic noise. The analysis is deliberately explicit and constructive: every claim is proved by elementary modular arithmetic, and every table can be regenerated with short reference code.

---

## 2. Definitions and Notation

### 2.1 The residue lattice

Let $m\in\mathbb{N}$ be the modulus and let $s,u,v\in\mathbb{Z}$.

Define the **affine residue lattice**:

$$
r(a,b) \equiv s + u(a-1) + v(b-1) \pmod m.
\tag{2.1}
$$

We consider $a,b\in\mathbb{Z}$; in applications the domain is often $a,b\ge 1$.

We will frequently work with the canonical representative $r(a,b)\in\{0,1,\dots,m-1\}$.

### 2.2 Visibility windows and display filters

A **visibility window** is a subset $W\subseteq \mathbb{Z}^2$ (finite or infinite). The paper uses the triangular crop

$$
W_N := \{(a,b): a\ge 1,\ b\ge 1,\ a+b\le N\},
\tag{2.2}
$$

for an integer $N\ge 2$.

A **display filter** is a predicate $\chi:\mathbb{Z}_m\to\{0,1\}$ that decides whether a residue is shown. For example, the printable ASCII filter

$$
\chi_{\text{ASCII}}(x)=
\begin{cases}
1, & 33\le x \le 126,\\
0, & \text{otherwise},
\end{cases}
\tag{2.3}
$$

can be composed with a choice of character mapping $x\mapsto \text{chr}(x)$.

## 3. The Specific Instance: $(s,u,v,m)=(53,4,56,100)$

Throughout, unless otherwise stated, we analyze the concrete lattice

$$
r(a,b) \equiv 53 + 4(a-1) + 56(b-1) \pmod{100}.
\tag{3.1}
$$

A few immediate observations:

- Moving **down** one step ($a\mapsto a+1$) increases $r$ by $u=4$ modulo $100$.
- Moving **right** one step ($b\mapsto b+1$) increases $r$ by $v=56$ modulo $100$.
- The modulus is composite: $100=2^2\cdot 5^2$.

This is not inherently “random.” Any perceived randomness must come from the viewing constraints.

---

## 4. Basic Algebraic Structure

### 4.1 Additive congruential form

Equation (3.1) is affine linear in $(a,b)$ over $\mathbb{Z}$ and becomes affine linear over the ring $\mathbb{Z}_{100}$ after reduction.

Define the displacement vector $\Delta=(\Delta a,\Delta b)$. Then

$$
r(a+\Delta a,\ b+\Delta b) - r(a,b) \equiv 4\Delta a + 56\Delta b \pmod{100}.
\tag{4.1}
$$

Thus the lattice depends only on the subgroup generated by $4$ and $56$ in $\mathbb{Z}_{100}$.

### 4.2 Residue class restriction (mod 4)

Let

$$
g := \gcd(u,v,m)=\gcd(4,56,100)=4.
\tag{4.2}
$$

**Theorem 4.1 (Restriction to a coset).** For all $(a,b)$,

$$
r(a,b) \equiv s \pmod g.
\tag{4.3}
$$

*Proof.* Since $u(a-1)+v(b-1)$ is divisible by $g$, the remainder modulo $g$ is $s\bmod g$. Here $s=53\equiv 1\pmod 4$. $\square$

**Corollary 4.2.** The lattice can only take the $m/g=25$ values

$$
\{1,5,9,\dots,97\}.
\tag{4.4}
$$

This single fact already explains a key visual phenomenon: the lattice never produces residues congruent to $0,2,3\pmod 4$.

## 5. Exact Periodicity and the Fundamental Tile

### 5.1 Period in each axis

A 1D additive congruential sequence $x_{n+1}\equiv x_n+k\pmod m$ has period $m/\gcd(k,m)$.

Apply this to the lattice along each coordinate.

**Theorem 5.1 (Axis periods).**
For fixed $b$, the sequence $a\mapsto r(a,b)$ has period

$$
P_a = \frac{m}{\gcd(u,m)} = \frac{100}{\gcd(4,100)} = 25.
\tag{5.1}
$$

For fixed $a$, the sequence $b\mapsto r(a,b)$ has period

$$
P_b = \frac{m}{\gcd(v,m)} = \frac{100}{\gcd(56,100)} = 25.
\tag{5.2}
$$

*Proof.* Each step adds $u$ or $v$ modulo $m$, so the period is as above. $\square$

### 5.2 2D periodicity and tiling

**Theorem 5.2 (Fundamental tile).** The full lattice satisfies

$$
r(a+25,b)=r(a,b),\quad r(a,b+25)=r(a,b)
\tag{5.3}
$$

for all $a,b\in\mathbb{Z}$. Therefore the infinite grid is periodic with a **$25\times 25$ fundamental domain**.

*Proof.* Direct from $25u=25\cdot 4=100\equiv 0\pmod{100}$ and $25v=25\cdot 56=1400\equiv 0\pmod{100}$. $\square$

Thus any crop, no matter how large, is a repeated view of the same $25\times 25$ tile.

## 6. Reduction to a $\mathbb{Z}_{25}$ Model

The restriction in §4 suggests quotienting by $g=4$.

Define

$$
t(a,b) := \frac{r(a,b)-1}{4} \in \mathbb{Z}_{25},
\tag{6.1}
$$

since $r(a,b)\equiv 1\pmod 4$ guarantees integrality.

Substitute (3.1):

$$
\begin{aligned}
r(a,b)
&\equiv 53 + 4(a-1) + 56(b-1) \pmod{100}\\
&\equiv 1 + 4\Big(13 + (a-1) + 14(b-1)\Big) \pmod{100}.
\end{aligned}
\tag{6.2}
$$

Therefore

$$
t(a,b) \equiv 13 + (a-1) + 14(b-1) \pmod{25}.
\tag{6.3}
$$

This is the “true” state evolution: the lattice is a simple affine plane over $\mathbb{Z}_{25}$.

### 6.1 Why the horizontal direction “scrambles” in small crops

Within $\mathbb{Z}_{25}$, the horizontal step is $+14$.

Since

$$
\gcd(14,25)=1,
\tag{6.4}
$$

the map $x\mapsto x+14$ permutes all 25 states: iterating it cycles through every value before repeating.

Hence each fixed-$a$ row, as $b$ increases, runs through all $25$ distinct coset states in some order—this is the actual source of the visually “random” dispersal inside a small crop. No irrationality is involved: $56/4=14$ is an integer, and the mixing comes from invertibility modulo $25$.

## 7. Relationship to LCGs (and Why the Standard Full-Period Criteria Do Not Apply)

A standard LCG is

$$
X_{n+1} \equiv AX_n + C \pmod m,
\tag{7.1}
$$

with multiplier $A$.

Our 2D lattice is not of this form; it is a direct affine map from coordinates to residues. Along any straight traversal (e.g., $n\mapsto (a(n),b(n))$) the induced 1D sequence is generally *piecewise additive*, and in the special case of stepping by a fixed displacement $\Delta=(\Delta a,\Delta b)$ it becomes an **additive congruential generator**:

$$
X_{n+1} \equiv X_n + k \pmod m,
\quad k\equiv 4\Delta a + 56\Delta b \pmod m,
\tag{7.2}
$$

which corresponds to (7.1) with the degenerate multiplier $A=1$.

Therefore:

- The Hull–Dobell full-period conditions for (7.1) with $A\ne 1$ are not the right analysis tool here.
- The correct tool is the additive period formula $m/\gcd(k,m)$.

If one wants a strict analogy: the lattice is a **2D additive congruential field** with step vectors $(1,0)$ and $(0,1)$ mapping to increments $4$ and $56$.

## 8. Windowing Effects: Why Crops Can Look Random

The generator is fully periodic and low-state (25 values), yet small windows can conceal this because:

1. The fundamental tile (25) is larger than the crop scale typically inspected.
2. The crop is not aligned to the tile boundaries, so local repeats may not be visually adjacent.
3. Representational filters (ASCII, “print only digits,” “blank outside bounds”) further fragment the perceived structure.

### 8.1 The triangular crop size

For $W_N$ in (2.2), the number of lattice points is

$$
|W_N| = \sum_{a=1}^{N-1} (N-a)
= \sum_{k=1}^{N-1} k
= \frac{(N-1)N}{2}.
\tag{8.1}
$$

For $N=10$, $|W_{10}|=\frac{9\cdot 10}{2}=45$.

### 8.2 Expected printable fraction under residue-class restriction

Because $r(a,b)\in\{1,5,\dots,97\}$, the number of residues falling into the printable band $[33,126]$ is the count of values in that set between 33 and 97:

$$
\{33,37,41,45,49,53,57,61,65,69,73,77,81,85,89,93,97\},
\tag{8.2}
$$

which is 17 values. Therefore, under an assumption of uniform sampling over the 25 residues (often approximately true over a full tile),

$$
p_{\text{print}} \approx \frac{17}{25}=0.68.
\tag{8.3}
$$

A substantially smaller observed visible fraction (e.g., near $0.35$) implies that the “visible” rule is not *only* printable ASCII on $r(a,b)$; it must include an additional gating mechanism (e.g., a different residue mapping, a second modulus, a masking rule, or a more selective character band). This becomes a useful diagnostic: the observed ratio fingerprints the true gating function.

## 10. General Theory for $r(a,b)=s+u(a-1)+v(b-1)\pmod m$

### 10.1 Value set size

Let

$$
g=\gcd(u,v,m).
\tag{10.1}
$$

Then

$$
r(a,b)\equiv s \pmod g,
\tag{10.2}
$$

so the image lies in a coset of size at most $m/g$.

### 10.2 Periods

Axis periods generalize immediately:

$$
P_a = \frac{m}{\gcd(u,m)},\qquad P_b=\frac{m}{\gcd(v,m)}.
\tag{10.3}
$$

### 10.3 Reduction to a quotient modulus

Let $g=\gcd(u,v,m)$ and define $m'=m/g$. For residues in the correct coset define

$$
t(a,b)=\frac{r(a,b)-s_0}{g}\pmod{m'},
\tag{10.4}
$$

where $s_0$ is a chosen lift of $s\bmod g$. Then

$$
t(a,b) \equiv t_0 + u'(a-1)+v'(b-1)\pmod{m'},
\tag{10.5}
$$

with $u'=u/g$, $v'=v/g$, and $t_0$ determined by $s$.

## 11. Structural Tests (Why It Is Not Hash-Like)

True cryptographic hash diffusion is nonlinear and avalanche-like. In contrast, (3.1) is an affine map; its structure is maximally “lattice-like.” Two diagnostic properties:

1. **Affine predictability:** from any two adjacent residues in a row or column, all others are determined by constant differences.
2. **Low rank in differences:** second differences vanish:
   $$
   \Delta_a\Delta_b\, r(a,b)=0\pmod m.
   \tag{11.1}
   $$

This is the opposite of cryptographic diffusion, where higher-order differences behave pseudorandomly.

---

## 12. “Visibility Ratios” as Diagnostics (Including the Claimed $\approx 0.35$)

A central empirical claim in the originating notes was a ratio near

$$
H\approx 0.34906585\approx \frac{\pi}{9}.
\tag{12.1}
$$

One example mentioned:

$$
\frac{45}{129}\approx 0.3488.
\tag{12.2}
$$

- The number 45 is exactly $|W_{10}|$ from (8.1).
- The denominator 129 is not a natural count arising from $W_N$ for small $N$. Therefore $129$ must come from a different counting regime (e.g., a rectangular crop, a mixed filter, multiple tiles, or a second constraint).

Given a precisely defined visible set $V\subseteq W$:

$$
V := \{(a,b)\in W:\chi(r(a,b))=1\},
\tag{12.3}
$$

the visibility ratio is

$$
\rho := \frac{|V|}{|W|}.
\tag{12.4}
$$

Because $r$ takes only $m/g$ values, $\rho$ depends strongly on the filter $\chi$, the window geometry, and how uniformly the window samples the fundamental tile. The right next step is to define $W$ and $\chi$ precisely and compute $\rho$.

## 13. Fibonacci–$e$ Numerical Note (Correction)

A quoted line was:

> $n=30$, $F_n=832040$, $e_n=2.718280194740024$, error $=1.6337\times 10^{-6}$; “the error is close to $\varphi$.”

That is false as written.

- $\varphi\approx 1.6180339887$.
- $1.6337\times 10^{-6}$ is not close to $1.618$.
- It is only close to $\varphi\times 10^{-6}$, which is not meaningful without a principled scaling argument.

Treat digit coincidences as hypotheses requiring replication under controlled definitions, not as evidence.

## 14. Conclusion

The grid

$$
r(a,b)\equiv 53+4(a-1)+56(b-1)\pmod{100}
$$

is a clean example of “hidden order in apparent chaos.” Its structure is not cryptographic and not genuinely random; it is an affine congruential lattice with:

- image restricted to one residue class modulo 4,
- exact axis periods 25,
- a $25\times 25$ repeating tile,
- a reduction to a simple $\mathbb{Z}_{25}$ model with horizontal increment $+14$ that permutes all states.

The “random” appearance arises from the projection pipeline: modulus, crop, and display filter. Once the observer aligns to the generating frame, the apparent entropy collapses to a trivially computable rule.

# Appendix C. Reference Implementation (Python)

The following code reproduces all tables and supports arbitrary windows and filters.

```python
from typing import Callable, Iterable, Tuple, List

def residue(a: int, b: int, s: int = 53, u: int = 4, v: int = 56, m: int = 100) -> int:
    \"\"\"Affine residue lattice r(a,b) = (s + u(a-1) + v(b-1)) mod m.\"\"\"
    return (s + u*(a-1) + v*(b-1)) % m

def window_triangle(N: int) -> List[Tuple[int,int]]:
    \"\"\"Points (a,b) with a>=1, b>=1, a+b<=N.\"\"\"
    pts = []
    for a in range(1, N):
        for b in range(1, N-a+1):
            pts.append((a,b))
    return pts

def ascii_printable(x: int) -> bool:
    return 33 <= x <= 126

def visibility_ratio(
    pts: Iterable[Tuple[int,int]],
    filt: Callable[[int], bool],
    *,
    s: int = 53, u: int = 4, v: int = 56, m: int = 100
) -> float:
    pts = list(pts)
    if not pts:
        return 0.0
    vis = 0
    for a,b in pts:
        if filt(residue(a,b,s=s,u=u,v=v,m=m)):
            vis += 1
    return vis / len(pts)

def fundamental_tile(size: int = 25, *, s: int = 53, u: int = 4, v: int = 56, m: int = 100):
    return [[residue(a,b,s=s,u=u,v=v,m=m) for b in range(1,size+1)] for a in range(1,size+1)]

if __name__ == \"__main__\":
    # Example: N=10 triangle
    pts = window_triangle(10)
    rho = visibility_ratio(pts, ascii_printable)
    print(\"Triangle points:\", len(pts))  # 45
    print(\"Printable ratio:\", rho)

    # Verify axis period 25
    for k in range(1, 30):
        if residue(1+k, 1) == residue(1, 1):
            print(\"Vertical repeat at k =\", k); break
    for k in range(1, 30):
        if residue(1, 1+k) == residue(1, 1):
            print(\"Horizontal repeat at k =\", k); break
```

# Appendix D. Diagnostic Checklist (If a Display “Looks Random”)

Given any displayed residue field:

1. Measure constant differences along axes: are they constant modulo $m$?
2. Compute $g=\gcd(\Delta_a,\Delta_b,m)$: does the field restrict to a coset mod $g$?
3. Compute axis periods $m/\gcd(\Delta_a,m)$ and $m/\gcd(\Delta_b,m)$.
4. Reduce to $m'=m/g$ for the clean state evolution.
5. Test whether step increments are invertible in $m'$: if yes, rows/cols permute all states.

If steps are constant and mixed second differences vanish, the field is affine and not hash‑like.
