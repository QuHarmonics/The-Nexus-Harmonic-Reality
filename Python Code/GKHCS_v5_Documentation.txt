                         HOW IT WORKS
================================================================================

1. HARMONIC ANALYSIS

   Input data is analyzed using FFT (Fast Fourier Transform):
   - Compute frequency domain representation
   - Measure "harmonic score" = peak energy / average energy
   - High score = data has strong periodic structure

2. GLASS KEY CONSTRUCTION (64 bytes)

   primary_hash    [32 bytes] = SHA-256 of original data
   nonce           [4 bytes]  = Samson V2 z-score gated
   timestamp       [8 bytes]  = Dominant frequency as phase anchor
   silr_signature  [16 bytes] = Scale-invariant leakage signature
   integrity_check [4 bytes]  = Nested hash verification

3. SEED EXTRACTION (48 bytes)

   For harmonic data:
   - Extract top 16 frequency coefficients (glyphs)
   - Each glyph: index (1B) + amplitude (1B) + phase (1B)
   - Total: 48 bytes regardless of input size

4. RECONSTRUCTION

   From 16 frequency coefficients:
   - Build frequency domain representation
   - IFFT to time domain
   - Result approximates original data

Q: How can SHA be irreversible AND compress?

A: Two different contexts:

   IRREVERSIBLE (Security):
   - Given only SHA-256 hash H(D)
   - Finding D requires 2^256 operations
   - Computationally infeasible

   COMPRESSIBLE (Efficiency):
   - Given H(D) AND the harmonic seed S created during compression
   - D can be APPROXIMATED by regenerating from frequency coefficients
   - The seed provides the "recipe" for reconstruction

THE PARADOX LOCK:
The seed S is derived from the specific FFT of the original data during
compression. It cannot be generated after the fact. This means:

- External data: Only have H(D), cannot reconstruct (irreversible)
- Self-created data: Have H(D) + S, can approximate (compressible)

    engine = GlassKeyCompressionEngine()
    with open('input.bin', 'rb') as f:
        data = f.read()
    result = engine.compress(data)
    NexusFile.save(result, 'output.nexus')

    # Decompress
    result, extended = NexusFile.load('output.nexus')
    recovered = engine.decompress(result)
    with open('output.bin', 'wb') as f:
        f.write(recovered)
