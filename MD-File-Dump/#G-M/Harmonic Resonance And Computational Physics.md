### Section 5.1: Reframing the Traveling Salesman Problem

The classical formulation of the TSP is as follows: given a set of cities and the distances between every pair of cities, find the shortest possible route that visits each city exactly once and returns to the starting city. It is a problem of minimizing a linear sum of distances, ∑di​, over the set of all possible Hamiltonian cycles. The computational difficulty arises from the factorial growth in the number of possible tours as the number of cities increases.

The RHA reframes this problem entirely. The objective is shifted from finding the path of minimal *distance* to finding the path of maximal *harmonic coherence*. In this new paradigm, the \"cost\" of traversing an edge between two cities is not a simple scalar distance but a measure of the *dissonance* it introduces into the system. The optimal tour is the one that creates the most stable, resonant closed loop.
