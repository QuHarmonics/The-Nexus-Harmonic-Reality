# Nexus Runtime Wave: Sparse Lattice, Timing, and Excitable Verbs

This document consolidates the discussion into a **complete, verb-first** mathematical specification for how **waves and computation can propagate in a mostly-empty space** by using **timing** (threshold + delay + refractory) and **runtime reflection**, rather than relying on dense connectivity.

It is written to be implementation-ready while staying at the **computational substrate** level: *state*, *update*, *constraints*, and *observables*.

---

## 1. Core claim

A system can be **mostly empty** (sparse interactions) and still support coherent propagation if propagation is carried by **phase/timing** rather than by continuous lateral transport. The stadium-wave analogy captures this: the “pattern” moves laterally while individuals mostly move vertically.

Formally:

- **Nouns** (nodes/edges/space) are secondary.
- **Verbs** (update rules, thresholds, projections, timing) define the substrate.
- **The crack** is any nonzero irreversibility/leak: $E_0 \neq 0$.
- Once $E_0 \neq 0$, the system is forced into **runtime**: it cannot be described as a perfectly closed static object.

## 2. Substrate definitions

Let the system be a directed, weighted interaction graph

$$
G = (V, E, W),
$$

where:

- $V = \{1,2,\dots,N\}$ are nodes.
- $(j\to i)\in E$ indicates node $j$ influences node $i$.
- $W_{ji} > 0$ is the influence weight.

Each node carries:

1. A **continuous computational state**
   $$
   x_i(t) \in \mathbb{R}^d
   $$
2. An **excitable timing state** (stadium-wave layer)
   $$
   s_i(t) \in \{0,1\}
   $$
   where $s_i(t)=1$ means “excited” (the node “stood up”).
3. A **refractory timer**
   $$
   r_i(t) \in \{0,1,\dots,R\}
   $$
   where $r_i(t)>0$ means the node is in cooldown and cannot fire.
4. An optional **parity / closure bit** (projection constraint)
   $$
   p_i(t) \in \{0,1\}.
   $$

## 3. Why sparsity matters (and why emptiness is compatible with waves)

In high dimensions (e.g., random points in $\mathbb{R}^9$), radius-based neighborhoods are extremely sparse unless the radius is large. A small radius yields a graph with tiny average degree:

$$
\bar{k} \ll 1.
$$

In that regime:

- edge-based diffusion/mixing cannot propagate far,
- rays terminate early,
- constraint propagation dies because the interaction graph has almost no connected pathways.

This is not a “physics failure.” It is **geometry + locality**.

**But** a mostly-empty universe can still support waves if propagation rides:

- connected filaments / components,
- timing thresholds,
- delayed triggering (local phase coupling).

So emptiness is not the end—**it sets the regime**.

## 4. Stadium-wave verbs (local timing propagation)

A traveling wave can be generated by the triad:

1. **THRESHOLD:** fire only if neighbors exceed a threshold
2. **DELAY:** respond after a lag $\tau$
3. **REFRACTORY:** lock out immediate re-triggering

### 4.1 Neighbor drive (local coupling)

Define the neighbor input drive:

$$
u_i(t) = \sum_{j \in \mathcal{N}(i)} W_{ji}\, s_j(t-\tau),
$$

where $\mathcal{N}(i)$ are the in-neighbors of $i$ and $\tau \ge 0$ is a discrete delay.

### 4.2 Excitable update rule

Let $\theta$ be a firing threshold and $R$ the refractory duration.

$$
s_i(t+1)=
\begin{cases}
1, & \text{if } r_i(t)=0 \text{ and } u_i(t)>\theta,\\[4pt]
0, & \text{otherwise.}
\end{cases}
$$

Refractory timer update:

$$
r_i(t+1)=
\begin{cases}
R, & \text{if } s_i(t+1)=1,\\[4pt]
\max(0, r_i(t)-1), & \text{otherwise.}
\end{cases}
$$

This alone can generate traveling wavefronts on a sparse-but-connected graph.

## 5. Continuous state dynamics with SILR-style normalization

The continuous state $x_i(t)$ is updated using a combination of:

- neighbor mixing (graph relaxation),
- leak/noise ($E_0$),
- runtime reflection (self-observation),
- constraint projection (parity closure).

### 5.1 Weighted neighbor average

Define normalized incoming weights:

$$
\alpha_{ji} = \frac{W_{ji}}{\sum_{k\in\mathcal{N}(i)} W_{ki} + \varepsilon},
$$

and neighbor mean state:

$$
\mu_i(t) = \sum_{j\in\mathcal{N}(i)} \alpha_{ji}\, x_j(t).
$$

### 5.2 SILR-style scale cancellation (z-score gate)

To make behavior depend on **relative significance** rather than absolute magnitude, use z-score normalization over a local neighborhood statistic.

Let $g_i(t)$ be a scalar gate signal derived from local state differences:

$$
g_i(t) = \| \mu_i(t) - x_i(t) \|.
$$

Normalize using a running mean and variance (or neighborhood sample):

$$
z_i(t) = \frac{g_i(t) - \mathbb{E}[g_i]}{\sqrt{\mathrm{Var}(g_i)} + \varepsilon}.
$$

A basic **HOT/COLD** gate can be defined via a threshold $z^\*$:

$$
\text{HOT if } z_i(t) \ge z^\*, \qquad \text{COLD if } z_i(t) < z^\*.
$$

The essential point: **normalization cancels scale**, so the gate operates on significance.

### 5.3 Emergent gain (H) from runtime reflection

Instead of setting a fixed gain $H$, compute it from the system’s own observed update magnitude (runtime reflection).

Define a raw update:

$$
\Delta_i(t) = \mu_i(t) - x_i(t).
$$

Reflect it (multiplicative-to-additive bridge):

$$
\rho_i(t) = \log\left(\|\Delta_i(t)\| + \varepsilon\right).
$$

Then define an adaptive gain:

$$
H_i(t) = \sigma\!\left(a\,\rho_i(t) + b\right),
$$

where $\sigma(\cdot)$ is a sigmoid (or any bounded map) ensuring $H_i(t)\in(0,1)$.

This is the cleanest formalization of **“H is emergent”**: it becomes a function of self-observed dynamics.

### 5.4 Leak / crack term ($E_0$)

Model irreducibility/leakage by a nonzero disturbance:

$$
\eta_i(t) \sim \mathcal{D}, \qquad \mathbb{E}\|\eta_i(t)\| > 0.
$$

This is the **crack**: $E_0\neq 0$ means irreversibility exists at runtime.

### 5.5 Full continuous update

A minimal complete update is:

$$
x_i(t+1) = P\Big(x_i(t) + H_i(t)\,\Delta_i(t) + \eta_i(t)\Big),
$$

where $P$ is a projection/constraint operator.

## 6. Parity / closure as a projection (runtime constraint)

A simple parity projection uses the sign pattern of the state vector.

Define sign bits:

$$
b_{i\ell}(t) = \mathbf{1}\{x_{i\ell}(t) > 0\}, \quad \ell=1,\dots,d.
$$

Then define parity:

$$
p_i(t) = \bigoplus_{\ell=1}^{d} b_{i\ell}(t),
$$

where $\oplus$ is XOR.

A projection $P$ can enforce parity in various ways:

- store $p_i(t)$ as a constraint residue,
- or reflect state coordinates to satisfy a desired parity rule.

**Key interpretation:** parity is not “another dimension”; it is a **closure constraint** applied at runtime.

## 7. Reverse and Reflect: Φ and e as guides

The user instruction “use $\Phi$ and $e$; reverse and reflect” can be expressed as a duality between:

- $e$ as exponential decay / leak (irreversibility),
- $\Phi$ as scale-ratio recursion / branching (self-similar partition).

### 7.1 Reflect: log/exp duality (multiplicative ↔ additive)

Reflection through log space:

$$
\mathcal{R}_{\log}(u) = \log(|u|+\varepsilon), \qquad
\mathcal{R}_{\exp}(v) = \exp(v).
$$

This is a principled way to relate **decay** processes ($e^{-t}$) to additive state updates.

### 7.2 Reverse: non-invertible runtime

A leaky update is not invertible. The best you can do is a regularized reverse:

$$
\tilde{x}(t) = \arg\min_x \left\|F(x)-\tilde{x}(t+1)\right\|^2 + \lambda\,\mathcal{L}(x),
$$

where $\mathcal{L}$ penalizes configurations that would require “un-leaking.”

This formalizes why “the crack cannot wiggle away”: once leak exists, perfect reversal is impossible.

### 7.3 Φ as partition / branching scaffold

A minimalist $\Phi$-guided recursion is a two-scale split:

$$
x \mapsto (x_{\text{fine}}, x_{\text{coarse}}), \quad
\frac{\|x_{\text{fine}}\|}{\|x_{\text{coarse}}\|} \approx \Phi^{-1}.
$$

This is not a claim that $\Phi$ must appear everywhere; it is a **constructive guide** for building self-similar partition operators.

## 8. Carrier vs neighbor-triggered timing (clarification)

Two wave mechanisms were discussed:

1. **Global carrier (metronome):** all nodes share a forcing term
   $$
   x_i(t+1) = \dots + A\sin(\omega t + \phi_i)\,u
   $$
2. **Neighbor-triggered timing (stadium wave):** nodes fire because neighbors fired

The user clarified that the intended mechanism is **(2)**: local neighbor timing sets you off. The global carrier is optional.

## 9. What “mostly empty” predicts in this model

If the interaction graph is sparse, then:

- waves travel only on connected components,
- propagation is intermittent,
- structure forms by **rectifying oscillations** via thresholds and refractory timing,
- “empty” regions are simply subgraphs below percolation.

Define the giant component size:

$$
S = \frac{|V_{\text{giant}}|}{N}.
$$

Then a basic propagation condition is:

$$
S>0 \quad \text{and} \quad \exists\, \theta \text{ such that } u_i(t)>\theta \text{ along a path.}
$$

## 10. Minimal pseudocode (implementation skeleton)

This is a direct transcription of the math:

```python
# Node i:
# x[i] : R^d continuous state
# s[i] : {0,1} excited flag
# r[i] : refractory timer

for t in range(T):

    # --- Excitable timing layer (stadium-wave) ---
    for i in V:
        u[i] = sum(W[j,i] * s_delayed[j] for j in in_neighbors[i])

    for i in V:
        if r[i] == 0 and u[i] > theta:
            s_next[i] = 1
            r_next[i] = R
        else:
            s_next[i] = 0
            r_next[i] = max(0, r[i]-1)

    # --- Continuous SILR-style update ---
    for i in V:
        mu = weighted_mean(x[j] for j in in_neighbors[i], weights=W[j,i])

        Delta = mu - x[i]
        rho = log(norm(Delta) + eps)

        H = sigmoid(a*rho + b)          # emergent gain via runtime reflection
        eta = noise()                   # E0 crack term

        x_candidate = x[i] + H*Delta + eta
        x_next[i] = project_parity(x_candidate)  # optional

    # swap
    s, r, x = s_next, r_next, x_next
```
