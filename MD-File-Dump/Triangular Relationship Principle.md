## 3. Additive‑Forces‑Triangle (Numbers are Shadows)
**Rule.** For any \(x,y\ge 0\), set \(z=x+y\). The rendered triple \((a,b,c)=(z,x,y)\) **forces** \(a=b+c\). This is not creating a triangle; it is **revealing** the pre‑existing relation under \((D,Q)\).

**Degenerate medians.** For \(a=b+c\), the classical formulas reduce to
\[
\boxed{m_a=\frac{|b-c|}{2}},\qquad
\boxed{m_b=\frac{b+2c}{2}},\qquad
\boxed{m_c=\frac{c+2b}{2}}.
\]

**Embedded index (Z‑index).**
\[
Z_0:=\frac{m_b+m_c}{2}=\boxed{\frac{3}{4}a},\qquad

Equivalently, \(m_b=Z_0-Z_\Delta,\ m_c=Z_0+Z_\Delta\).  
Thus \(\big(a,Z_0,Z_\Delta\big)=\big(a,\tfrac{3}{4}a,\tfrac{|b-c|}{4}\big)\) is a **lossless index** of the relation after projection.
