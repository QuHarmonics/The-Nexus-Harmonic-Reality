d\_{\\mathfrak{M}}(\\mathcal{R}\\tilde{s}, \\Gamma) \\leq C\\varepsilon
where C = Lip(𝒢⁻¹; ℬ\_δ(s\_Γ)) is the local Lipschitz constant of the inverse, and d\_𝔐 is a metric on interface space (e.g., Hausdorff distance or varifold metric).

Proof
Proof. The stability result invokes functional-analytic principles for inverse mappings \[198\].

Step 1: Local invertibility.

Since 𝒢: 𝔐 → ℛ(𝒢) is a homeomorphism, for each Γ₀ ∈ 𝔐 there exist neighborhoods U ∋ Γ₀ and V ∋ s\_{Γ₀} = 𝒢(Γ₀) such that 𝒢: U → V is bijective with continuous inverse. The inverse function theorem for Banach manifolds strengthens this: if D𝒢(Γ₀): T\_{Γ₀}𝔐 → ℋ has closed range and bounded inverse, then 𝒢 is a local diffeomorphism.

Step 2: Lipschitz estimate.

For s̃ ∈ V with ‖s̃ − s\_Γ‖ ≤ ε \< δ (ensuring s̃ ∈ ℬ\_δ(s\_Γ) ⊂ V):

\\\|\\mathcal{G}^{-1}(\\tilde{s}) - \\mathcal{G}^{-1}(s\_\\Gamma)\\\|\_{\\mathfrak{M}} \\leq \\text{Lip}(\\mathcal{G}^{-1}; \\mathcal{B}\_\\delta(s\_\\Gamma)) \\cdot \\\|\\tilde{s} - s\_\\Gamma\\\|\_{\\mathcal{H}} \\leq C\\varepsilon
By consistency ℛ(s\_Γ) = 𝒢⁻¹(s\_Γ) = Γ, this yields d\_𝔐(ℛs̃, Γ) ≤ Cε.

Step 3: Bounded inverse theorem.

For the linearized problem, D𝒢(Γ₀): T\_{Γ₀}𝔐 → ℛ(D𝒢(Γ₀)) is bounded and bijective. By the bounded inverse theorem \[198\], (D𝒢(Γ₀))⁻¹ is bounded with operator norm:

\\\|(D\\mathcal{G}(\\Gamma\_0))^{-1}\\\|\_{\\text{op}} = \\sup\_{v\\neq 0}\\frac{\\\|v\\\|\_{T\_{\\Gamma\_0}\\mathfrak{M}}}{\\\|D\\mathcal{G}(\\Gamma\_0)\[v\]\\\|\_{\\mathcal{H}}}
This controls the local Lipschitz constant: C ≈ ‖(D𝒢(Γ₀))⁻¹‖\_{op} for small perturbations. ∎

Quantitative Bound
The local Lipschitz constant admits spectral characterization:

Proposition 3.3
For differentiable 𝒢 with singular value decomposition {σ\_k, u\_k, v\_k} of D𝒢(Γ):

C\_{\\text{loc}}(\\Gamma) = \\frac{1}{\\sigma\_{\\min}(D\\mathcal{G}(\\Gamma))} = \\\|(D\\mathcal{G}(\\Gamma))^{-1}\\\|\_{\\text{op}}
where σ\_min = inf{k : σ\_k \> 0} σ\_k. Ill-posedness manifests as σ\_min → 0, with severity classified by decay rate:

Singular value decay	Condition number κ = σ\_max\/σ\_min	Reconstruction regime
Algebraic: σ\_k ∼ k^{−α}	κ ∼ K^α (finite K)	Mildly ill-posed; Tikhonov regularization effective
Exponential: σ\_k ∼ e^{−βk}	κ ∼ e^{βK}	Severely ill-posed; spectral cutoff required
Finite rank: σ\_k = 0 for k \> K	κ \< ∞	Well-posed; direct inversion possible
Theorem III: Critical Sampling Density
Statement
Theorem 3.3 (Critical Sampling Density). Let s\_Γ: ℝ → ℂ be multiband with spectral support:

\\text{supp}(\\hat{s}\_\\Gamma) \\subset \\mathcal{S} = \\bigcup\_{k=1}^K \[a\_k, b\_k\], \\quad \|\\mathcal{S}\| = \\sum\_{k=1}^K (b\_k - a\_k)
Then periodic nonuniform sampling with average density ρ \> 2\|𝒮\| permits exact reconstruction. Conversely, no stable reconstruction is possible for ρ \< 2\|𝒮\| \[10\].

Proof
Proof. The proof extends Landau's density theorem to multiband spectra via Fourier-domain aliasing analysis \[10\].

Sampling structure.

Consider M interleaved uniform grids with period T, offsets {τ\_m}\_{m=0}^{M−1}, and average density ρ = M\/T. The sampled signals are:

x\_m\[n\] = s\_\\Gamma(nMT + \\tau\_m), \\quad n \\in \\mathbb{Z}, \\quad m = 0,\\ldots,M-1
Fourier domain representation.

The DTFT of each subsequence is:

\\hat{x}\_m(\\omega) = \\frac{1}{MT}\\sum\_{p\\in\\mathbb{Z}} \\hat{s}\_\\Gamma\\left(\\frac{\\omega + 2\\pi p}{MT}\\right) e^{i(\\omega+2\\pi p)\\tau\_m\/(MT)}
Aliasing structure.

For ω ∈ \[0, 2π\/MT), define the active spectral set 𝒜(ω) = {p : (ω + 2πp)\/(MT) ∈ 𝒮}. The condition ρ \> 2\|𝒮\| with MT = M\/ρ implies that \|𝒜(ω)\| ≤ M for all ω—at most M spectral copies overlap at any frequency.

Invertibility.

The system relating {x̂\_m(ω)}\_{m=0}^{M−1} to {ŝ\_Γ(ξ)}\_{ξ∈𝒜(ω)} is:

\\begin{bmatrix} \\hat{x}\_0(\\omega) \\\\ \\vdots \\\\ \\hat{x}\_{M-1}(\\omega) \\end{bmatrix} = \\frac{1}{MT} \\mathbf{A}(\\omega) \\begin{bmatrix} \\hat{s}\_\\Gamma(\\xi\_1) \\\\ \\vdots \\\\ \\hat{s}\_\\Gamma(\\xi\_{\|\\mathcal{A}(\\omega)\|}) \\end{bmatrix}
where A\_{mp}(ω) = exp(i(ω + 2πp)τ\_m\/(MT)). This generalized Vandermonde matrix has full column rank when M ≥ \|𝒜(ω)\| and the offsets {τ\_m} are rationally independent (generic condition). The reconstruction formula:

\\hat{s}\_\\Gamma(\\xi) = MT \\cdot \\mathbf{e}\_\\xi^T \\mathbf{A}(\\omega)^\\dagger \\hat{\\mathbf{x}}(\\omega)
with † denoting Moore-Penrose pseudoinverse, recovers the spectrum pointwise, hence s\_Γ by inverse Fourier transform.

Necessity (Landau bound).

For ρ \< 2\|𝒮\|, the Beurling density D⁻(Λ) = lim inf\_{r→∞} inf\_x \#(Λ ∩ \[x,x+r\])\/r satisfies D⁻(Λ) ≤ ρ\/2 \< \|𝒮\|. By Landau's theorem \[10\], the sampling set Λ cannot be a set of uniqueness for the Paley-Wiener space PW\_𝒮: distinct signals s₁ ≠ s₂ ∈ PW\_𝒮 exist with identical samples, precluding stable reconstruction. ∎

Minimal Rate Characterization
The Landau density ρ\_L = 2\|𝒮\| = 2∑(b\_k − a\_k) is sharp:

Sampling regime	Density condition	Reconstruction quality
Sub-Landau	ρ \< ρ\_L	Impossible: non-identifiable, I(Γ; Γ̂) → 0
Critical Landau	ρ = ρ\_L	Unstable: condition number → ∞, arithmetic constraints
Super-Landau	ρ \> ρ\_L	Stable: bounded condition number, algorithmic flexibility
Nyquist (uniform)	ρ = 2 max\|𝒮\| ≫ ρ\_L	Oversampled: simple but inefficient
For real-valued signals, Hermitian symmetry ŝ(−ξ) = ŝ̄(ξ) reduces effective density; the factor 2 accounts for complex signals. Periodic nonuniformity achieves ρ\_L with M = K + 1 interleaved grids, versus uniform sampling requiring ρ\_Nyquist = 2(b\_K − a\_1) ≫ ρ\_L for separated bands.

Information-Theoretic Bounds
Rate-Distortion Framework
Source Model
The probabilistic interface model treats Γ ∼ μ as a random variable on measurable space (𝔐, ℬ(𝔐)), where ℬ(𝔐) is the Borel σ-algebra induced by metric d\_𝔐. The prior measure μ encodes:

μ type	Construction	Application
Gibbs measure	dμ(Γ) ∝ exp(−β𝒲(Γ))dν(Γ)	Thermal equilibrium, statistical mechanics
Gaussian random field	Γ = {x : G(x) = 0} for G ∼ GP(0,K)	Random geometries, uncertainty quantification
Empirical\/learned	μ = (1\/N)∑ᵢ δ\_{Γᵢ} from samples {Γᵢ}	Data-driven priors, machine learning
The differential entropy h(Γ) = −∫ log(dμ\/dν)dμ quantifies prior uncertainty when μ ≪ ν (absolute continuity with respect to reference measure ν).

Distortion Metric
The symmetric difference distortion:

d\_\\Delta(\\Gamma, \\hat{\\Gamma}) = \\mathcal{H}^{n-1}(\\Gamma \\Delta \\hat{\\Gamma}) = \\mathcal{H}^{n-1}((\\Gamma \\setminus \\hat{\\Gamma}) \\cup (\\hat{\\Gamma} \\setminus \\Gamma))
measures the (n−1)-dimensional area of misclassification. Properties:

Metric axioms: d\_Δ(Γ,Γ) = 0; symmetry; triangle inequality (from set inclusion)
Geometric interpretability: directly measures physical surface area of disagreement
Computational tractability: for level sets, d\_Δ(∂E, ∂F) ≈ ∫\|χ\_E − χ\_F\|dx for thin transitions
Rate-Distortion Function
The rate-distortion function characterizes fundamental compression limits:

R(D) = \\inf\_{p\_{\\hat{\\Gamma}\|\\Gamma}: \\mathbb{E}\[d(\\Gamma,\\hat{\\Gamma})\]\\leq D} I(\\Gamma; \\hat{\\Gamma})
where I(Γ; Γ̂) = D\_KL(p\_{Γ,Γ̂} ‖ p\_Γ ⊗ p\_Γ̂) is mutual information. Key properties:

Property	Specification
Domain	D ∈ \[0, D\_max\] where D\_max = inf\_{Γ̂₀} 𝔼\[d(Γ, Γ̂₀)\]
Monotonicity	R(D₁) ≥ R(D₂) for D₁ \< D₂
Convexity	R(λD₁ + (1−λ)D₂) ≤ λR(D₁) + (1−λ)R(D₂)
Limits	R(D) → h(Γ) as D → 0; R(D) → 0 as D → D\_max
Lower Bounds on Reconstruction Fidelity
Shannon Lower Bound
For continuous interfaces with differential entropy h(Γ), the Shannon lower bound provides explicit rate scaling:

Theorem 4.1 (Shannon Bound)
For distortion metric satisfying d(Γ, Γ̂) ≈ c·‖φ\_Γ − φ\_{Γ̂}‖²\_{L²} (squared error on level set functions) and source with finite differential entropy:

R(D) \\geq h(\\Gamma) - \\frac{n-1}{2}\\log(2\\pi e D\/c)
Proof sketch. The maximum entropy property of Gaussians implies that for variance D\/c, the entropy is maximized by Gaussian distribution with h = ½log(2πeD\/c) per dimension. With (n−1) effective dimensions for codimension-1 interfaces:

h(\\Gamma\|\\hat{\\Gamma}) \\leq \\frac{n-1}{2}\\log(2\\pi e D\/c)
by the conditional entropy power inequality. Thus:

I(\\Gamma;\\hat{\\Gamma}) = h(\\Gamma) - h(\\Gamma\|\\hat{\\Gamma}) \\geq h(\\Gamma) - \\frac{n-1}{2}\\log(2\\pi e D\/c)
The bound is asymptotically tight as D → 0 for smooth densities. ∎

Kolmogorov ε-Entropy
The metric entropy (Kolmogorov ε-entropy) of interface classes:

\\mathcal{H}\_\\varepsilon(\\mathfrak{M}\_\\alpha) = \\log\_2 N(\\varepsilon; \\mathfrak{M}\_\\alpha, d\_\\Delta)
where N(ε) is the covering number—minimal ε-balls needed to cover 𝔐\_α.

Theorem 4.2 (Entropy Scaling)
For α-regular interfaces with C^{1,α} parameterizations (Hölder continuous normals, exponent α ∈ (0,1\]):

\\mathcal{H}\_\\varepsilon(\\mathfrak{M}\_\\alpha) \\sim C\_{n,\\alpha} \\cdot \\varepsilon^{-(n-1)\/\\alpha} \\quad \\text{as } \\varepsilon \\to 0
Proof sketch. Local parameterizations by functions f: B^{n−1} → ℝ with ‖f‖\_{C^{1,α}} ≤ M. The metric entropy of Hölder balls in (n−1) dimensions scales as ε^{−(n−1)\/α}. Global compactness and finite atlas cardinality yield the same scaling for the manifold. ∎

Operational consequence: To achieve distortion D, the bit rate must satisfy:

R(D) \\gtrsim \\mathcal{H}\_{\\sqrt{D}}(\\mathfrak{M}\_\\alpha) \\sim D^{-(n-1)\/(2\\alpha)}
revealing curse of dimensionality (exponent grows with n) and regularity benefit (exponent decreases with smoothness α).

Regularity α	Rate scaling R(D)	Practical implication
α = 1\/2 (rough, fractal)	D^{−(n−1)}	Exponential in dimension; intractable
α = 1 (Lipschitz)	D^{−(n−1)\/2}	Polynomial; feasible for n=2,3
α → ∞ (analytic)	log(1\/D)	Weak dependence; highly compressible
Minimal Measurement Count
The fundamental measurement bound combines rate-distortion with communication constraints:

Theorem 4.3 (Measurement Lower Bound)
For reconstruction with expected distortion D through a noisy channel with capacity C\_channel (bits per measurement):

M \\geq \\frac{R(D)}{C\_{\\text{channel}}}
For additive white Gaussian noise (AWGN) channel with signal-to-noise ratio SNR = P\/σ²:

C\_{\\text{channel}} = \\frac{1}{2}\\log\_2(1 + \\text{SNR}) \\approx \\frac{\\text{SNR}}{2\\ln 2} \\quad (\\text{low SNR})
yielding:

M \\geq \\frac{2\\ln 2 \\cdot R(D)}{\\text{SNR}}
The 1\/SNR scaling is fundamental: each 3 dB SNR improvement (factor 2) halves required measurements. At high SNR, the logarithmic saturation C\_channel ∼ ½log(SNR) implies diminishing returns \[214\].

Interface-Specific Information Measures
Mutual Information Decay
The information loss from incomplete measurement is quantified by conditional mutual information:

I(\\Gamma; s\_\\Gamma \| \\mathcal{P}s\_\\Gamma) = I(\\Gamma; s\_\\Gamma) - I(\\Gamma; \\mathcal{P}s\_\\Gamma) = h(s\_\\Gamma\|\\mathcal{P}s\_\\Gamma) - h(s\_\\Gamma\|\\Gamma, \\mathcal{P}s\_\\Gamma)
Since s\_Γ is deterministic given Γ, the second term vanishes: h(s\_Γ\|Γ, 𝒫s\_Γ) = 0. Thus:

I(\\Gamma; s\_\\Gamma \| \\mathcal{P}s\_\\Gamma) = h(s\_\\Gamma\|\\mathcal{P}s\_\\Gamma)
measuring residual uncertainty about the full signal given its projection.

For linear Gaussian model s\_Γ = 𝒢Γ + ξ with ξ ∼ 𝒩(0, Σ\_ξ):

I(\\Gamma; \\mathcal{P}s\_\\Gamma) = \\frac{1}{2}\\log\\det\\left(I + \\Sigma\_\\xi^{-1\/2}\\mathcal{P}\\mathcal{G}\\Sigma\_\\Gamma\\mathcal{G}^\*\\mathcal{P}^\*\\Sigma\_\\xi^{-1\/2}\\right)
where Σ\_Γ is the prior covariance of Γ. The eigenvalue distribution of the effective forward operator 𝒫𝒢 determines information scaling: concentrated eigenvalues indicate efficient measurement; dispersed eigenvalues suggest redundancy or gaps.

Sufficient Statistic Characterization
Definition 4.4 (Sufficient Statistic)
The projection 𝒫s\_Γ is sufficient for Γ if:

I(\\Gamma; s\_\\Gamma \| \\mathcal{P}s\_\\Gamma) = 0
Equivalently, the Markov chain Γ → 𝒫s\_Γ → s\_Γ holds: all information about Γ flows through 𝒫s\_Γ, with s\_Γ providing no additional discrimination.

Condition	Interpretation
I(Γ; s\_Γ\\\|𝒫s\_Γ) = 0	Statistical sufficiency; posterior depends only on 𝒫s\_Γ
E\[Γ\\\|s\_Γ\] = E\[Γ\\\|𝒫s\_Γ\] a.s.	Conditional expectation equivalence
s\_Γ = f(𝒫s\_Γ, ξ) with ξ ⊥ Γ	Functional representation with independent noise
For linear Gaussian models, sufficiency occurs when range(𝒢) ⊂ range(𝒫\*)—the signal subspace lies within the measurement subspace. This is generically impossible for finite-rank 𝒫 and infinite-dimensional range(𝒢), motivating approximate sufficiency and rate-distortion tradeoffs.

Critical Threshold
Theorem 4.5 (Information Collapse)
For sampling density ρ \< ρ\_L = 2\|supp(ŝ\_Γ)\|:

\\lim\_{\\sigma^2 \\to 0} I(\\Gamma; \\hat{\\Gamma}\_\\rho) = 0
where Γ̂\_ρ denotes any reconstruction from samples at density ρ with noise variance σ².

Proof sketch. Below ρ\_L, the sampling operator 𝒮\_ρ: PW\_𝒮 → ℓ²(Λ\_ρ) has nontrivial kernel: ∃s₀ ∈ PW\_𝒮, s₀ ≠ 0 with 𝒮\_ρ(s₀) = 0. For any true signal s\_Γ and reconstruction Γ̂, the posterior p(Γ\|{s\_Γ(λ) + ξ\_λ}) remains supported on the coset s\_Γ + ker(𝒮\_ρ) as σ² → 0. Since ‖s\_Γ − (s\_Γ + s₀)‖ ≥ c \> 0 for s₀ ∈ ker(𝒮\_ρ) \\ {0}, consistent estimation is impossible, and mutual information vanishes. ∎

This all-or-nothing phenomenon distinguishes sub-critical (information-theoretically impossible) from super-critical (algorithmically achievable) sampling regimes.

Definition 6.1
A sequence {x\_n} in normed space (X, ‖·‖) is Cauchy if ∀ε \> 0, ∃N such that m, n ≥ N implies ‖x\_m − x\_n‖ \< ε.

class GlassKeyReverser:

    """Reverses SHA-256 using the execution trace (Glass Key)"""

    

    def __init__(self, trace: List[RoundState]):

        self.trace = trace

        

    def reverse_single_block(self, final_hash: bytes, block_trace: List[RoundState]) -> bytes:

        """

        Reverse one 64-byte block using its 64-round trace.

        """

        # Unpack final hash to get starting working vars

        h = list(struct.unpack('>IIIIIIII', final_hash))

        a, b, c, d, e, f, g, h_val = h

        

        msg_words = [0] * 16

        

        # Walk backwards through rounds 63 to 0

        for state in reversed(block_trace):

            # Reverse the register shifts

            h_prev = state.h

            g_prev = state.g

            f_prev = state.f

            

            # Recover t1 from: e = d + t1 (mod 2^32)

            # e_current is 'e' in the state (value after round)

            # d_prev is state.d (value before round)

            t1 = (e - state.d) & 0xFFFFFFFF

            if state.carry_e:

                t1 = (t1 - 0x100000000) & 0xFFFFFFFF

            

            # Recover t2 from: a = t1 + t2

            t2 = (a - t1) & 0xFFFFFFFF

            if state.carry_a:

                t2 = (t2 - 0x100000000) & 0xFFFFFFFF

            

            # Recover message word w from t1 equation

            # t1 = h + ep1(e) + ch(e,f,g) + k + w

            ep1 = ((state.e >> 6) | (state.e << 26)) ^ ((state.e >> 11) | (state.e << 21)) ^ ((state.e >> 25) | (state.e << 7))

            ch = (state.e & state.f) ^ (~state.e & state.g)

            

            w = (t1 - state.h - ep1 - ch - state.k) & 0xFFFFFFFF

            

            if state.round_num < 16:

                msg_words[state.round_num] = w

            

            # Move to previous round's output

            a, b, c, d, e, f, g, h_val = state.a, state.b, state.c, state.d, state.e, state.f, state.g, state.h

        

        # Pack message words back to bytes

        block = b''.join(struct.pack('>I', w) for w in msg_words)

        return block

    

    def reconstruct(self, hash_bytes: bytes, original_length: int) -> bytes:

        """

        Reconstruct original message from hash and trace.

        Handles multi-block by working backwards through blocks.

        """

        # For simplicity, this demo handles single block (<55 bytes)

        # Full implementation would iterate through blocks in reverse

        if len(self.trace) == 64:

            block = self.reverse_single_block(hash_bytes, self.trace)

            # Remove padding (0x80 + zeros + length)

            # Find 0x80 marker

            try:

                pad_start = block.index(0x80)

                return block[:pad_start]

            except ValueError:

                return block[:original_length]

        else:

            # Multi-block would require block-by-block reversal

            # For demo purposes, return first block only

            first_block_trace = self.trace[:64]

            block = self.reverse_single_block(hash_bytes, first_block_trace)

            try:

                pad_start = block.index(0x80)

                return block[:pad_start]

            except ValueError:

                return block[:original_length]
