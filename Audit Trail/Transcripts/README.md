## Transcript contract

Preserve provider, conversation identifier, speaker role, original message order, timestamps and their provenance where supplied, and related paper, code, seal and execution addresses. Unknown dates remain unknown. A later correction links back to the original record instead of rewriting it.

The global chronological research index remains OPEN. Public transcript releases require a review of personal information, credentials, third-party rights and applicable file licenses.
