# NEXUS — Audit Trail

[← NEXUS home](../README.md) · [Start here](../START_HERE.md) · [Published Paper Archive](Published%20Paper%20Archive/)

The archive preserves the developmental record of the Nexus research program. Its earlier papers are retained as historical research artifacts, including approaches that subsequent work refines or supersedes. The native-domain reading path is a separate, curated entry point into current research.

## Public collection

The [Published Paper Archive](Published%20Paper%20Archive/) contains 754 PDF files at the base snapshot of this documentation update. This is a count of files, not unique publications or verified publication dates. Some files are notebook renderings, revisions or companion artifacts.

- Cite the version actually read; use its DOI when supplied by the source.
- Do not replace an earlier document with a later interpretation.
- Link an experiment to its inputs, implementation, recorded output and correction history wherever those records are available.
- Record dates only when their source supports them. A Git upload date is not automatically a discovery date.

A chronology and mathematical dependency index can be built from the historical record without renaming its source artifacts. Those indexes are not yet complete.
