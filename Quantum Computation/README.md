## What this domain covers

This section investigates connections between native binary transformations and quantum-computation language, including reversible gates, symmetries, phase-like structures, observer/readout models, and possible compilation routes. A reversible classical machine and a physical quantum device are not interchangeable.

**Relationship to the foundation:** the [NEXUS Domain](../The%20Nexus%20Domain/) defines the native machine. Research here explores particular constructions, applications, or comparators without changing that domain by assumption.

## How to read the work

1. Write operators and state spaces explicitly.
2. Separate classical 𝔽₂ reversibility from complex-linear/unitary structure.
3. Provide proof obligations for any proposed quantum correspondence.
4. Distinguish simulations and algebra from hardware demonstrations.

> **Boundary:** Matching an operator pattern does not establish an implemented quantum algorithm or a physically realizable quantum system.

**Research ledger:** **STANDS** = proved identity or external theorem; **RUNS** = executed readout with stated scope; **OPEN** = missing derivation/link; **DEAD END** = observed landing owned elsewhere; **PULL** = external or physical interpretation. These words are not interchangeable.
