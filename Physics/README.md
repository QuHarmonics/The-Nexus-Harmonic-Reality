## What this domain covers

This area holds investigations that compare NEXUS operators with physical concepts: motion, inertia, fields, symmetry, spectra, atomic and nuclear organization, and dynamical systems. The native machine is developed separately; a physical claim requires an explicit mapping between domain observables and measurements.

**Relationship to the foundation:** the [NEXUS Domain](../The%20Nexus%20Domain/) defines the native machine. Research here explores particular constructions, applications, or comparators without changing that domain by assumption.

## How to read the work

1. Name the exact NEXUS observable being compared.
2. State units, calibration, parameter choices, and the dataset or theorem used.
3. Distinguish mathematical analogy from a physical derivation or prediction.
4. Keep corrections and independent measurements alongside the interpretation.

> **Boundary:** External physics is a comparator, not a tuning knob for the core; physical interpretation remains an adapter unless a bridge is explicitly derived.

**Research ledger:** **STANDS** = proved identity or external theorem; **RUNS** = executed readout with stated scope; **OPEN** = missing derivation/link; **DEAD END** = observed landing owned elsewhere; **PULL** = external or physical interpretation. These words are not interchangeable.
