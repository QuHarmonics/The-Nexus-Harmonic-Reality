Interior-body prediction — sealed before execution
Date: 2026-10-20

Definitions:
- J_n(x) is n-bit reversal.
- P_n(x)=J_n(x) when J_n(x) != x, and P_n(x)=complement(x) when x is a palindrome.
- A word x is canonical iff x < P_n(x).
- c_n(x)=sgn(J_n(x)-x), and Delta_n(p)=sum_{x<p} c_n(x).

Prediction P1 (all-width rank identity):
Let pi_n(p) be the signed number of palindromes below p:
  pi_n(p)=#{x<p: J_n(x)=x, msb(x)=0}
          -#{x<p: J_n(x)=x, msb(x)=1}.
Then for every threshold 0 <= p <= 2^n,
  rank_n(p) := #{x<p: x is canonical}
             = (p + Delta_n(p) + pi_n(p))/2.
Reason: split x<p into x<J(x), x>J(x), and palindromes; Delta is the first count minus the second, while pi corrects the palindrome half-count into the actual canonical-palindrome count.

Prediction P2 (compact palindrome correction):
If t_n(p)=#{x<p: J_n(x)=x} and M=2^ceil(n/2) is the total number of n-bit palindromes, then
  pi_n(p)=min(t_n(p), M-t_n(p)).
For p<N, let h=floor(n/2), H=2^h, U=floor(p/H), B=p mod H. The number of palindromes below p is
  t_n(p)=U + 1[rev_h(U >> (n mod 2)) < B].
At p=N, t_n(N)=M. This follows because the palindromes, in numeric order, have all msb-zero palindromes first and all msb-one palindromes second.

Prediction P3 (whole-body address readout):
For a canonical representative p, rank_n(p) is its sorted canonical rank. Invert rank_n to select p at a given pre-swap rank i, and its latitude is wt(p)-n/2. The physical ring's center swap is applied after ranking: it exchanges positions M-1 and M. Away from this center pair, the left face is exactly the digit-sum waveform of the rank-selected canonical word; the right face follows the partner reflection. For a canonical palindrome p (its first bit is 0), t_n(p)=pi_n(p)=its half-word integer u, recovering the earlier special formula rank_n(p)=(p+u+Delta_n(p))/2. A noncanonical palindrome has signed correction pi_n(p)=M-t_n(p), not u.
