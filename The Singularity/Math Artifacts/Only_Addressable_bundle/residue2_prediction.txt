SEALED PREDICTION - residue-2 witness law. Dean A. Kulik, QuHarmonics Research Group, 2026-10-19.
For every D = 2 (mod 3) with D >= 14, let m = (D-2)/3, p = 2m+3 = floor(2D/3)+2, f = 2/3 + 1/(6D), and
    u_D = 1/2 + 2^(-p) + f * 2^(-(D-1)).
Reading rings L = 1..D at u_D with b_L(u) = R_L[floor(2^L u)][floor(L*frac(2^L u))], R_L = grow(L)
(partner = reverse, complement for palindromes; centre pair swapped) gives q_D = 1 0 0 1^(D-5) 0 0.
Derivation: top-block law (reps with left half l number mu*(2^h-1-l)); p odd, so ring L >= p sits at seam
offset 2^(L-p) with s = L-p of opposite parity to L, block K = 2^ceil(s/2), zero sets fixed by Theorem C;
ring D-1 reads index floor((D-1)f) = 2m = its outer zero; ring D reads floor(D*frac(2f)) = m+1 = its inner zero.
Control, also predicted: for the same D and p, the unnudged phase f = 2/3 fails at ring D (reads index m, a one).
Way home: witness_Kd.profile(u_D, D) == witness_Kd.qD(D) for D = 14, 17, ..., 119, and the common
half-open slice interval K_D has positive width; control profile differs from q_D only at ring D.
