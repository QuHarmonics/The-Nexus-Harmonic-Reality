NEXUS REVERSE-THE-GAP — WIDTH-THREE EXCHANGE
WHAT: derive the minimum binary register width permitting an exchange that (i) has no fixed state, (ii) is reversible/closed, and (iii) contains a nonlinear interaction term.

Compiler route:
- Width n has domain GF(2)^n. “Cannot leave” is typed as a bijection. “Cannot hold still” is typed as a fixed-point-free map.
- For n=1, every bijection is affine because AGL(1,2) has 2 elements, equal to 2!.
- For n=2, every bijection is affine because |AGL(2,2)|=2^2(2^2-1)(2^2-2)=24=4!.
- For n=3, form an explicit fixed-point-free involution by conjugating an affine free involution X with the self-inverse nonlinear Toffoli map T: F=T o X o T, where T(a,b,c)=(a,b,c xor ab), and X(a,b,c)=(a xor c,b xor 1,c).

Prediction: F is bijective, satisfies F(F(x))=x, has no fixed point, and has nonzero degree-2 ANF terms. Width 3 is therefore the first admissible width for a nonlinear exchange under these formalized constraints.

Important degree distinction: for a 3-bit permutation, “top nonlinear degree” means degree n-1=2. The full cubic ANF coefficient (degree n=3) is zero in each output coordinate for the constructed permutation. Do not call a quadratic term a cubic top-degree term.

Way home: F^{-1}=F. The read-back supplies the input x by applying the same composed route a second time. All 8 addresses are checked only as the return/readout of this explicit route; no candidate maps are generated or scanned.
