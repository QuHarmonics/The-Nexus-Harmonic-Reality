NEXUS COMPILER SPACE — PRE-RUN PREDICTION SEAL
Created before executing nexus_compiler_space.py.

The run will define one graded word domain S[b,n], one same-LEN difference operator, and typed transformations between arbitrary source and target LEN. It will test these predictions:

1. For every tested base b and LEN n, the modular difference map (x,y) -> y-x mod b is onto S[b,n], and each difference has exactly b^n ordered preimages. Binary XOR is the b=2 instance.
2. Difference at LEN n+1 decomposes exactly into the prior n-coordinate difference plus one new digit difference; this recursion is witnessed pairwise, not inferred from a table of counts alone.
3. A total transformation S[b,n] -> S[b,m] is uniquely represented by its ordered output table, a word of LEN m*b^n in base b. For binary S[2,2] -> S[2,2], the 256 distinct transformations correspond one-to-one with all 256 8-bit table words.
4. Transformation composition is a typed direct jump from source LEN to target LEN; it need not pass through every intervening LEN. Replacing a route by its composed table retains action but can merge distinct route histories.
5. A lower-LEN transformation lifted into a larger state can act on its exposed interface while preserving the untouched context exactly. Projection from LEN n to reader width k has uniform fibers of size b^(n-k).
6. Equal-LEN edge fusion is a reversible representation change when ordered contents remain, and the fusion forest is the same stream/domain data represented as nested objects.
7. The recursively encoded endomorphism table produces an unbounded sequence of finite compiler-description LEN values L' = L*b^L; this gives an executable recursive schema, not an enumeration of the infinite domain.
8. Existing concrete adapters will be re-used: reversible SHA-256 round with W,K retained, BBP quotient/residual recurrence, and ring/surface mappings. These adapters have different signatures and will not be declared the same transformation.

The script will report exact finite witnesses and distinguish theorem-level formulas from enumerations. It will not treat a finite run as proof of an ontology of matter or a digest-only inverse of SHA.
