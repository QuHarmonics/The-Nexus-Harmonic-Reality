FRAMEWORK ALIGNMENT
-------------------
This engine treats SHA-256 not as a cryptographic function but as a 64-wheel
odometer anchored at the empty-hash base state. Every input is a delta (Δ)
applied to the substrate. Each slot is a destination — a compiler slot reading
the same Prior Completion geometry at a specific resolution.

BASE STATE (Origin Coordinate k=0)
----------------------------------
Empty string hash:
e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855

This is the "all wheels at rest" position. Every message turns the crank and
moves each wheel by some signed delta on the 0-15 hex circle.

QUERY GEOMETRIES
----------------
1. STEPS   — Sequential slot traversal with configurable stride (1,2,4,8,16)
2. SKIPS   — Every Nth slot, reading the odometer at coarse resolution
3. GAPS    — Circular distance between paired slots (adjacent + schedule-coupled)
4. SHAPES  — Nonlinear trajectories through slot space:
   - triangle   : triangular numbers mod 64
   - spiral     : Archimedean spiral sampling
   - wave       : sine-wave sampled slots
   - diamond    : expansion from center (slot 32)
   - star       : 13-step coprime cycle (visits all 64 slots)
   - schedule   : follows SHA message schedule dependency chain

HOW TO USE
----------
Run the standalone script:
    python3 hex_odometer.py

It will create ./hex_odometer_output/ and populate it with the full dataset.

Query the CSVs with standard tools:
    # Find which slots carry most often for input '1' repeated 32 times
    grep "repeat_1" hex_odometer_carries.csv | grep ",1$"

    # Find gap patterns for schedule-coupled pairs
    awk -F',' '$4==7' hex_odometer_gaps.csv | head

    # Follow a shape trajectory
    grep "triangle" hex_odometer_shapes.csv | grep "repeat_f"

NEXT STEPS
----------
The odometer is mapped. The next layer is the "tuner" — finding which input
Δ produces a desired odometer reading. This is not inversion (message from
hash). It is navigation: steering the 64 wheels to a target coordinate by
composing the right sequence of cranks.

The schedule constraint (σ₀/σ₁ recurrence) is the transmission geometry.
Understanding it means understanding how a turn at slot t propagates to
t-2, t-7, t-15, t-16. That is the gear train.
