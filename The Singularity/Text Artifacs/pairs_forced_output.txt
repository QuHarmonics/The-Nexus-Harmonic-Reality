== A  the nested ring: every word once, and the ring is its own partner read backwards ==
  LEN  1:      2 words, each once: True, partner(ring[i]) == ring[N-1-i]: True
  LEN  2:      4 words, each once: True, partner(ring[i]) == ring[N-1-i]: True
  LEN  3:      8 words, each once: True, partner(ring[i]) == ring[N-1-i]: True
  LEN  4:     16 words, each once: True, partner(ring[i]) == ring[N-1-i]: True
  LEN  8:    256 words, each once: True, partner(ring[i]) == ring[N-1-i]: True
  LEN 12:   4096 words, each once: True, partner(ring[i]) == ring[N-1-i]: True
  LEN 16:  65536 words, each once: True, partner(ring[i]) == ring[N-1-i]: True
  ring 2 = 00100111  (the 2-bit circle as drawn)

== B  the pairing is the orbit's own: a cyclic orbit of even length has exactly one involution ==
  rotations of  4 bits: elements of order 2 = [2]  -> the half-turn R^2 only
  rotations of  6 bits: elements of order 2 = [3]  -> the half-turn R^3 only
  rotations of  8 bits: elements of order 2 = [4]  -> the half-turn R^4 only
  rotations of 10 bits: elements of order 2 = [5]  -> the half-turn R^5 only
  rotations of 12 bits: elements of order 2 = [6]  -> the half-turn R^6 only
  rotations of 16 bits: elements of order 2 = [8]  -> the half-turn R^8 only

== C  the pair readout x XOR Hx: cancels what the pair shares, lands one layer down ==
  half-turn n= 4: residual always in Fix(H) True; both members give one residual True; what cancels completely = Fix(H) True; |Fix|    4, |image|    4
  half-turn n= 6: residual always in Fix(H) True; both members give one residual True; what cancels completely = Fix(H) True; |Fix|    8, |image|    8
  half-turn n= 8: residual always in Fix(H) True; both members give one residual True; what cancels completely = Fix(H) True; |Fix|   16, |image|   16
  half-turn n=10: residual always in Fix(H) True; both members give one residual True; what cancels completely = Fix(H) True; |Fix|   32, |image|   32
  half-turn n=12: residual always in Fix(H) True; both members give one residual True; what cancels completely = Fix(H) True; |Fix|   64, |image|   64
  mirror    n= 4: residual always in Fix(H) True; both members give one residual True; what cancels completely = Fix(H) True; |Fix|    4, |image|    4
  mirror    n= 6: residual always in Fix(H) True; both members give one residual True; what cancels completely = Fix(H) True; |Fix|    8, |image|    8
  mirror    n= 8: residual always in Fix(H) True; both members give one residual True; what cancels completely = Fix(H) True; |Fix|   16, |image|   16
  mirror    n=10: residual always in Fix(H) True; both members give one residual True; what cancels completely = Fix(H) True; |Fix|   32, |image|   32
  mirror    n=12: residual always in Fix(H) True; both members give one residual True; what cancels completely = Fix(H) True; |Fix|   64, |image|   64
  half-turn: Fix = {uu}, the whole layer below; residual of x = uv is (u^v)(u^v)

== D  the 8-bit orbit of 1B, three readouts ==
  orbit: 1B 36 6C D8 B1 63 C6 8D
  whole orbit read at once (XOR of all 8):            00   -> everything cancels, nothing left
  pairs (x, half-turn x):                            (1B,B1)->AA  (36,63)->55  (6C,C6)->AA  (D8,8D)->55
  residual orbit: AA <-> 55, period 2: the bare flip, one layer down (1010 / 0101)
  fold again: 1B -> 1010 -> 00   (1010 is half-turn fixed at 4 bits, so it cancels completely next)

== E  folded all the way down, the pair readout is the difference engine ==
  n= 4: pair-difference folded to the bottom == Mobius/ANF transform: True
  n= 8: pair-difference folded to the bottom == Mobius/ANF transform: True
  n=16: pair-difference folded to the bottom == Mobius/ANF transform: True
  read upward, every layer is (u, u^v): a copy and a difference. That is the whole build, from 2 bits.

== F  on the nested ring, the pair residual is a mirror word; palindrome pairs give all ones ==

  LEN  6: every pair residual is a palindrome True; palindrome pairs give 111111: True
  LEN  8: every pair residual is a palindrome True; palindrome pairs give 11111111: True
  LEN 10: every pair residual is a palindrome True; palindrome pairs give 1111111111: True
