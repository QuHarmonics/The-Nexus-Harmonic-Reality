The meta-analysis by Binggeli and Weinstein (1986) established the foundational pattern: rapidly proliferating cancer cells maintain resting membrane potentials of \*\*−10 to −30 mV\*\*, while quiescent/differentiated cells rest at \*\*−60 to −90 mV\*\*.

\### DNA sequence compression ratios  
  
  
  
The theoretical baseline is \*\*2 bits per nucleotide\*\* for random sequences. Specialized DNA compressors consistently achieve better ratios:  
  
  
  
| Algorithm | Bits/Base | Reference |  
  
|-----------|-----------|-----------|

| GenCompress | ~1.74 | Approximate repeats |  
  
| XM | 1.76-1.80 | Context + memory models |  
  
| GeCo2/GeCo3 | 1.80-1.90 | Neural network mixing |  
  
  
  
\*\*GeCo3\*\* (Silva et al., \*GigaScience\* 2020, DOI: 10.1093/gigascience/giaa119) represents the current state-of-art, achieving \*\*2.4-7.1% improvement\*\* over previous methods using neural network probability mixing. Reference-based compression achieves over \*\*99% reduction\*\* (human genome: ~3 GB → ~4 MB).  
  
  
  
\*\*Shannon entropy measurements:\*\*

\### Fourier analysis and the f=1/3 periodicity signal  
  
  
  
The defining spectral signature of protein-coding DNA is a \*\*sharp peak at frequency f=1/3\*\* in the power spectrum, corresponding to the triplet codon structure. This signal is absent in non-coding regions.  
  
  
  
\*\*Key quantitative studies:\*\*  
  
\- Tiwari et al. (\*CABIOS\* 1997) analyzed >5.5 million bp establishing the GeneScan algorithm  
  
\- Howe & Song (\*Nucleic Acids Research\* 2013, DOI: 10.1093/nar/gks1261) applied categorical spectral envelope analysis to \*\*75,979 GENCODE transcripts\*\*, finding \*\*76% exhibit significant 3-base periodicity\*\*  
  
\- Trotta (\*Journal of Theoretical Biology\* 2011) demonstrated 3-periodicity exceeds predictions from codon usage alone—the codon-frequency component accounts for 71.9% of mRNA variability  
  
  
  
The discrete Fourier transform method constructs four binary indicator sequences for A, C, G, T, then computes power spectrum: |Ũ\[k\]|² = |Ã\[k\]|² + |C̃\[k\]|² + |G̃\[k\]|² + |T̃\[k\]|². A peak at position N/3 (sequence length N) indicates coding potential.  
  
  
  
\### Nucleosome positioning and 10 bp periodicity  
  
  
  
Independent of the coding periodicity, DNA exhibits \*\*~10 bp periodic recurrence\*\* of dinucleotides (AA/TT/TA and GC) that facilitates chromatin packaging:  
  
  
  
\- Period: \*\*10.0-10.4 bp\*\* matching DNA helical repeat (9.7-11 bp)  
  
\- AA/TT: 10.26 bp periodicity in chromatin  
  
\- GG/CC: 10.0 bp periodicity  
  
\- Wang et al. (\*NAR\* 2012) found 10.1 bp periodicity with probability amplitude 0.2 accurately predicts nucleosome positions  
  
  
  
\*\*Wavelet analysis\*\* (Modified Gabor Wavelet Transform) enables multi-scale detection of these periodicities and outperforms standard FFT for non-stationary genomic features.

        p = evals / evals.sum()

        gini = 1 - np.sum(p**2)

    import numpy as np, pandas as pd
    from scipy.optimize import curve_fit
    from sklearn.model_selection import GroupKFold
    from sklearn.linear_model import LogisticRegression
    from sklearn.metrics import roc_auc_score
    
    eis = pd.read_csv('eis.csv')  # long format
    
    def cole_cole(f, R_inf, R0, tau, alpha):
        # Z*(ω) = R_inf + (R0 - R_inf) / (1 + (jωτ)^(1-α))
        w = 2*np.pi*f
        # complex exponent via Havriliak–Negami with β=1
        jwta = (1j*w*tau)**(1 - alpha)
        Z = R_inf + (R0 - R_inf) / (1 + jwta)
        return np.vstack([Z.real, Z.imag]).T
    
    def fit_sample(df):
        f = df['frequency_hz'].values
        Z = df['real_ohm'].values + 1j*df['imag_ohm'].values
        def model_concat(f, R_inf, R0, tau, alpha):
            return cole_cole(f, R_inf, R0, tau, alpha).ravel()
        y = np.vstack([Z.real, Z.imag]).T.ravel()
        p0 = [df['real_ohm'].min(), df['real_ohm'].max(), 1e-3, 0.2]
        bounds = ([0, 0, 1e-6, 0.0],[np.inf, np.inf, 1.0, 1.0])
        popt, _ = curve_fit(model_concat, f, y, p0=p0, bounds=bounds, maxfev=20000)
        R_inf, R0, tau, alpha = popt
        deltaR = R0 - R_inf
        return dict(R_inf=R_inf, R0=R0, tau=tau, alpha=alpha, deltaR=deltaR)
    
    feat_rows = []

    #!/usr/bin/env python3
    # Compare the Nexus Verb helix to an experimental structure.
    # Outputs RMSD, residues/turn, pitch, hydrophobic moment, i->i+4 checks, and an overlay plot.
    
    import os, sys, math, argparse, numpy as np, matplotlib.pyplot as plt
    from Bio.PDB import PDBList, PDBParser, Select, PPBuilder
    from Bio.SeqUtils.ProtParam import ProteinAnalysis
    
    # ---------- Nexus Verb (alpha-helix) ----------
    def verb_helix_coords(n, theta_deg=100.0, rise=1.50, L=3.80):
        theta = np.deg2rad(theta_deg)
        r = math.sqrt((L**2 - rise**2) / (4.0 * (math.sin(theta/2.0)**2)))
        coords = np.zeros((n,3))
        for i in range(n):
            ang = i*theta
            coords[i] = [r*math.cos(ang), r*math.sin(ang), i*rise]
        # center
        coords -= coords.mean(axis=0)
        return coords, r, theta, rise
    
    # ---------- PDB utilities ----------
    def fetch_pdb_if_needed(pdb_arg):
        if os.path.isfile(pdb_arg):
            return pdb_arg
        code = pdb_arg.lower().replace('.pdb','')
        pdbl = PDBList()
        fn = pdbl.retrieve_pdb_file(code, pdir='.', file_format='pdb')
        return fn
    
    def get_chain_coords_and_seq(pdb_path, chain_id):
        parser = PDBParser(QUIET=True)
        structure = parser.get_structure('s', pdb_path)
        model = next(structure.get_models())
        # grab chain; if not found, take first
        chain = None
        for ch in model:
            if ch.id.strip() == chain_id.strip():
                chain = ch
                break
        if chain is None:
            chain = next(model.get_chains())
        # sequence via PPBuilder
        ppb = PPBuilder()
        seq = ""
        ca_coords = []
        res_ids = []
        for pp in ppb.build_peptides(chain):
            seq += str(pp.get_sequence())
            for res in pp:
                if 'CA' in res:
                    ca_coords.append(res['CA'].coord)
                    res_ids.append((res.get_id()[1], res.get_resname()))
        if len(ca_coords)==0:
            raise RuntimeError("No Cα atoms found.")
        return np.array(ca_coords), seq, res_ids
    
    def best_window_for_sequence(chain_seq, target_seq):
        # simple sliding best match (Hamming) over exact-length windows
        m, n = len(chain_seq), len(target_seq)
        if n>m:
            return 0, min(m,n)
        best_i, best_score = 0, -1
        for i in range(m-n+1):
            window = chain_seq[i:i+n]
            score = sum(a==b for a,b in zip(window, target_seq))
            if score > best_score:
                best_score, best_i = score, i
        return best_i, best_i+len(target_seq)
    
    # ---------- Alignment (Kabsch) ----------
    def kabsch(P, Q):
        # P, Q: Nx3 (centered)
        C = P.T @ Q
        V, S, Wt = np.linalg.svd(C)
        d = np.linalg.det(V @ Wt)
        D = np.diag([1,1,np.sign(d)])
        R = V @ D @ Wt
        return R
    
    def rmsd(A, B):
        return np.sqrt(np.mean(np.sum((A-B)**2, axis=1)))
    
    # ---------- Metrics ----------
    eisenberg = {
     'A':0.62,'C':0.29,'D':-0.90,'E':-0.74,'F':1.19,'G':0.48,'H':-0.40,'I':1.38,
     'K':-1.50,'L':1.06,'M':0.64,'N':-0.78,'P':0.12,'Q':-0.85,'R':-2.53,'S':-0.18,
     'T':-0.05,'V':1.08,'W':0.81,'Y':0.26
    }
    
    def hydrophobic_moment(seq, theta_deg=100.0):
        theta = math.radians(theta_deg)
        vx = vy = 0.0
        for i,aa in enumerate(seq):
            h = eisenberg.get(aa,0.0)
            ang = i*theta
            vx += h*math.cos(ang)
            vy += h*math.sin(ang)
        mu = math.sqrt(vx*vx+vy*vy)/max(1,len(seq))
        ang = math.degrees(math.atan2(vy,vx))
        return mu, ang
    
    def residues_per_turn_from_proj(coords):
        # estimate via average azimuthal step
        xy = coords[:,:2]
        ang = np.unwrap(np.arctan2(xy[:,1], xy[:,0]))
        steps = np.diff(ang)
        mean_step = np.mean(steps)
        return 2*math.pi/abs(mean_step)
    
    def pitch_from_z(coords):
        # linear fit of z vs residue index => rise; multiply by res/turn
        z = coords[:,2]; i = np.arange(len(coords))
        rise = np.polyfit(i, z, 1)[0]
        rpt = residues_per_turn_from_proj(coords)
        return rise*rpt, rise, rpt
    
    def i_to_ip4_checks(coords):
        dlist = []
        anglist = []
        for i in range(len(coords)-4):
            a, b = coords[i], coords[i+4]
            d = np.linalg.norm(b-a)
            dlist.append(d)
            if i+5 < len(coords):
                v1 = b - a
                v2 = coords[i+5]-coords[i+1]
                c = np.dot(v1,v2)/(np.linalg.norm(v1)*np.linalg.norm(v2)+1e-9)
                ang = math.degrees(math.acos(np.clip(c,-1,1)))
                anglist.append(ang)
        return np.mean(dlist), np.std(dlist), (np.mean(anglist) if anglist else np.nan)
    
    def radius_of_gyration(coords):
        return math.sqrt(np.mean(np.sum((coords - coords.mean(axis=0))**2, axis=1)))
    
    # ---------- Plot ----------
    def plot_overlay(expC, verbC, outpng, title="Experimental vs Verb"):
        from mpl_toolkits.mplot3d import Axes3D  # noqa
        fig = plt.figure(figsize=(12,4))
        ax = fig.add_subplot(131, projection='3d')
        ax.plot(expC[:,0],expC[:,1],expC[:,2],'k-',lw=2,label='Exp')
        ax.plot(verbC[:,0],verbC[:,1],verbC[:,2],'r--',lw=2,label='Verb')
        ax.legend(); ax.set_title(title)
    
        ax2 = fig.add_subplot(132)
        ax2.plot(expC[:,0],expC[:,1],'k.-',label='Exp')
        ax2.plot(verbC[:,0],verbC[:,1],'r.--',label='Verb')
        ax2.set_aspect('equal'); ax2.grid(alpha=0.3); ax2.legend()
        ax2.set_title('XY projection')
    
        ax3 = fig.add_subplot(133)
        ax3.plot(np.arange(len(expC)),expC[:,2],'k.-',label='Exp z')
        ax3.plot(np.arange(len(verbC)),verbC[:,2],'r.--',label='Verb z')
        ax3.set_title('z vs index'); ax3.grid(alpha=0.3); ax3.legend()
    
        plt.tight_layout(); plt.savefig(outpng, dpi=150); plt.close()
    
    # ---------- Main ----------
    def main():
        ap = argparse.ArgumentParser()
        ap.add_argument('--pdb', required=True, help='PDB id (e.g., 2MLT) or path to PDB file')
        ap.add_argument('--chain', default='A', help='Chain id (default A)')
        ap.add_argument('--seq', default='GIGAVLKVLTTGLPALISWIKRKRQQ', help='Target sequence (melittin by default)')
        ap.add_argument('--theta', type=float, default=100.0)
        ap.add_argument('--rise',  type=float, default=1.50)
        ap.add_argument('--out',   default='verb_overlay')
        args = ap.parse_args()
    
        pdb_path = fetch_pdb_if_needed(args.pdb)
        exp_all, chain_seq, res_ids = get_chain_coords_and_seq(pdb_path, args.chain)
    
        # window the experimental to the target sequence length (best match)
        i0, i1 = best_window_for_sequence(chain_seq, args.seq)
        exp = exp_all[i0:i1].copy()
        if len(exp) != len(args.seq):
            # fallback: truncate to min length
            n = min(len(exp), len(args.seq))
            exp = exp[:n]; args.seq = args.seq[:n]
    
        # generate verb helix
        verb, r, theta, p = verb_helix_coords(len(args.seq), args.theta, args.rise, L=3.80)
    
        # Kabsch align verb to experimental
        E = exp - exp.mean(axis=0)
        V = verb - verb.mean(axis=0)
        R = kabsch(V, E)
        V_aln = (V @ R.T)
    
        # RMSD and metrics
        val_rmsd = rmsd(E, V_aln)
        pitch, rise_est, rpt_est = pitch_from_z(V_aln)
        mu, mu_ang = hydrophobic_moment(args.seq, theta_deg=args.theta)
        d_i4_mean, d_i4_std, ang_i4 = i_to_ip4_checks(V_aln)
        rg_exp = radius_of_gyration(E); rg_verb = radius_of_gyration(V_aln)
    
        print("="*64)
        print(f"PDB: {args.pdb}  Chain: {args.chain}  Window: [{i0}:{i1}]  N={len(args.seq)}")
        print(f"Verb params: theta={args.theta:.1f}°, rise={args.rise:.2f} Å, radius={r:.2f} Å")
        print("-"*64)
        print(f"RMSD (Cα):          {val_rmsd:.2f} Å")
        print(f"Residues/turn:      {rpt_est:.2f}  (theory: {360/args.theta:.2f})")
        print(f"Pitch:              {pitch:.2f} Å  (theory: {(360/args.theta)*args.rise:.2f})")
        print(f"i→i+4 distance:     {d_i4_mean:.2f} ± {d_i4_std:.2f} Å   (α-helix ≈ 5.4–6.0 Å)")
        print(f"i→i+4 angle proxy:  {ang_i4:.1f}°   (heuristic consistency)")
        print(f"Hydrophobic moment: {mu:.3f} @ {mu_ang:.1f}°")
        print(f"Rg (exp / verb):    {rg_exp:.2f} Å / {rg_verb:.2f} Å")
        print("-"*64)
    
        outpng = f"{args.out}.png"
        plot_overlay(E, V_aln, outpng, title=f"{args.pdb} vs Verb (N={len(args.seq)})")
        print(f"Plot saved: {outpng}")
        print("="*64)
    
    if __name__ == '__main__':
        main()
