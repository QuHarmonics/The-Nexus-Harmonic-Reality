# Contributing

Independent research, reproduction, documented corrections and noncommercial experimentation are welcome. See [research-first licensing](LICENSE.md).

Use a GitHub issue or pull request for public, nonsensitive contributions. Identify the source address and revision, input/output contract, dependencies, evidence, actual execution scope and any unresolved link. Preserve original records rather than silently altering historical outcomes.

Submit only material you are authorized to share, and identify the applicable license and attribution. This document does not require copyright assignment or establish a blanket contributor license agreement. The terms for incorporation and redistribution must be compatible with the applicable license and clarified where necessary.

Do not include secrets, personal data, private transcripts or unrelated proprietary code.
