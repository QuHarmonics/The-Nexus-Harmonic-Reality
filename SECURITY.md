# Security and privacy reports

For sensitive security or privacy concerns in this public research repository, contact QuHarmonics through [its website](https://quharmonics.com/) rather than posting secrets, private records, exploit details or personal information in a public issue.

Include the affected file or commit, a concise description and a safe way to reproduce the issue. Avoid accessing data or systems without authorization. No bug bounty, response-time guarantee or authorization for security testing is implied.

Research implementations should not be assumed production-hardened. See [research disclaimer](DISCLAIMER.md).
