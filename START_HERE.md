## 4. Use the ledger

**STANDS** — mathematical identity or external theorem. **RUNS** — derived route with a documented executed readout. **OPEN** — specified requirement whose route remains missing. **DEAD END** — landing owned by another structure. **PULL** — external interpretation.

Read the exact source and its return path. Preserve corrections as part of the history.
