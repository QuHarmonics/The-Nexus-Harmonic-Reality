## Event contract

Retain stable source address, original time where supplied, precision, timestamp provenance, author or speaker, event type, claims, related artifacts, predecessors, corrections and supersessions. Unknown dates remain unknown. Export time, Git upload time, manuscript date and discovery time are distinct.

Event types: introduction, derivation, prediction, execution, correction, transfer, generalization, publication, supersession and open dependency. Retain message order even where timestamps are absent; merge event streams without replacing local order.
