# Lightweight public portal

This branch preserves the documentation, legal notices and public interface. Original research sources are available at [the archived revision](https://github.com/QuHarmonics/The-Nexus-Harmonic-Reality/tree/462e8e558eafb9f333b7726eddf0e7a527ee93e1). The historical catalog is pinned to its original snapshot.

## Enable GitHub Pages

1. Settings → Pages → Build and deployment → Deploy from a branch.
2. Select `clean-public-portal-20261126` and `/docs` (or main after merging).
3. Save. The static site does not need hosted AI, build runners or paid services.

No Git history rewrite has been performed. Historical object storage and published-site size are distinct. The repository's original URL is unchanged.
