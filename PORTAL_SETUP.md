## Enable GitHub Pages

1. Settings → Pages → Build and deployment → Deploy from a branch.
2. Select main and /docs.
3. Save.

The static site runs on the visitor's browser. No cloud AI, custom server or paid runner is required. The GitHub Pages setting must be enabled by the repository administrator. Historical Git storage is separate from the published-site size; this update does not rewrite history.
